## Concept of an Antiderivative of a Function

### a) Definition of Antiderivative and Indefinite Integral

Let $f(x)$ be a function defined on an interval $K$ (or a segment, or a half-interval).
• A function $F(x)$ is called an antiderivative of the function $f(x)$ on $K$ if:
$$F'(x) = f(x), \quad \forall x \in K$$
• Theorem on the family of antiderivatives: Suppose $F(x)$ is an antiderivative of $f(x)$ on $K$. Then:
  1. For any constant $C$, the function $F(x) + C$ is also an antiderivative of $f(x)$ on $K$;
  2. Conversely, if $G(x)$ is an antiderivative of $f(x)$ on $K$, then there exists a constant $C$ such that $G(x) = F(x) + C$ for all $x \in K$.
• The expression $F(x) + C$ ($C \in \mathbb{R}$) is called the family of antiderivatives (or the indefinite integral) of $f(x)$ on $K$, denoted by:
$$\int f(x) dx = F(x) + C$$
Notes:
\- The expression $f(x)dx$ is called the differential of the antiderivative $F(x)$, denoted by $dF(x) = F'(x)dx = f(x)dx$.
\- Every continuous function on an interval $K$ possesses an antiderivative on that interval.
\- When finding an antiderivative without explicitly specifying the domain $K$, it is understood to be on each interval of the natural domain of the function.

### b) Examples and Practice on Identifying Antiderivatives

**Example 1:** Given the function $f(x) = x^2 - 2x$. Among the functions $F(x) = \frac{x^3}{3} - x^2$ and $G(x) = \frac{x^3}{3} + x^2$, which function is an antiderivative of $f(x)$ on $\mathbb{R}$?

Solution to Example 1:
• Taking the derivative of each function:
  $$F'(x) = \left(\frac{x^3}{3} - x^2\right)' = x^2 - 2x = f(x), \quad \forall x \in \mathbb{R}.$$
  $$G'(x) = \left(\frac{x^3}{3} + x^2\right)' = x^2 + 2x.$$
• Since $F'(x) = f(x)$ for all $x \in \mathbb{R}$, $F(x)$ is an antiderivative of $f(x)$ on $\mathbb{R}$.
• The function $G(x)$ is not an antiderivative of $f(x)$ on $\mathbb{R}$ because at $x = 1$, $G'(1) = 3 \ne -1 = f(1)$.

**Practice 1:** Which of the following functions is an antiderivative of $f(x) = x + \frac{1}{x}$ on the interval $(0; +\infty)$:
$$F(x) = \frac{1}{2}x^2 + \ln x; \quad G(x) = \frac{x^2}{2} - \ln x.$$

Solution to Practice 1:
• For all $x \in (0; +\infty)$, we have:
  $$F'(x) = \left(\frac{1}{2}x^2 + \ln x\right)' = x + \frac{1}{x} = f(x).$$
  $$G'(x) = \left(\frac{x^2}{2} - \ln x\right)' = x - \frac{1}{x} \ne f(x).$$
• Therefore, $F(x) = \frac{1}{2}x^2 + \ln x$ is an antiderivative of $f(x)$ on $(0; +\infty)$.

## Fundamental Properties of Antiderivatives

### a) Linearity Properties of Antiderivatives

Assume that $f(x)$ and $g(x)$ are continuous on $K$, and $k$ is a non-zero constant. Then:
• Property 1 (Constant multiple rule):
$$\int k f(x) dx = k \int f(x) dx \quad (k \ne 0)$$
• Property 2 (Sum and difference rules):
$$\int [f(x) + g(x)] dx = \int f(x) dx + \int g(x) dx$$
$$\int [f(x) - g(x)] dx = \int f(x) dx - \int g(x) dx$$

### b) Examples and Practice on Applying Properties

**Example 4:** Find:
a) $\int (x^2 + x) dx$;
b) $\int (4x^3 - 3x^2) dx$.

Solution to Example 4:
• a) Applying the sum rule:
  $$\int (x^2 + x) dx = \int x^2 dx + \int x dx = \frac{x^3}{3} + \frac{x^2}{2} + C.$$
• b) Applying the difference rule and constant multiple rule:
  $$\int (4x^3 - 3x^2) dx = 4\int x^3 dx - 3\int x^2 dx = 4 \cdot \frac{x^4}{4} - 3 \cdot \frac{x^3}{3} + C = x^4 - x^3 + C.$$

**Practice 4:** Find:
a) $\int (3x^2 + 1) dx$;
b) $\int (2x - 1)^2 dx$.

Solution to Practice 4:
• a) $\int (3x^2 + 1) dx = 3\int x^2 dx + \int 1 dx = 3 \cdot \frac{x^3}{3} + x + C = x^3 + x + C$.
• b) Expanding the integrand:
  $$\int (2x - 1)^2 dx = \int (4x^2 - 4x + 1) dx = 4\int x^2 dx - 4\int x dx + \int 1 dx = \frac{4}{3}x^3 - 2x^2 + x + C.$$

## Antiderivatives of Common Elementary Functions

### a) Antiderivatives of Power Functions

• $\int 0 dx = C$
• $\int 1 dx = x + C$
• $\int x^\alpha dx = \frac{x^{\alpha + 1}}{\alpha + 1} + C \quad (\alpha \ne -1)$
• $\int \frac{1}{x} dx = \ln |x| + C \quad (x \ne 0)$

**Example 6:** Find:
a) $\int \sqrt{x} dx$ ($x > 0$);
b) $\int \frac{1}{x^3} dx$;
c) $\int \left(2x^2 + \frac{3}{\sqrt{x}}\right) dx$.

Solution to Example 6:
• a) Writing in power form with rational exponent:
  $$\int \sqrt{x} dx = \int x^{1/2} dx = \frac{x^{1/2 + 1}}{\frac{1}{2} + 1} + C = \frac{2}{3}x^{3/2} + C = \frac{2}{3}x\sqrt{x} + C.$$
• b) $\int \frac{1}{x^3} dx = \int x^{-3} dx = \frac{x^{-3 + 1}}{-3 + 1} + C = -\frac{1}{2}x^{-2} + C = -\frac{1}{2x^2} + C$.
• c) $\int \left(2x^2 + \frac{3}{\sqrt{x}}\right) dx = 2\int x^2 dx + 3\int x^{-1/2} dx = 2 \cdot \frac{x^3}{3} + 3 \cdot \frac{x^{1/2}}{1/2} + C = \frac{2}{3}x^3 + 6\sqrt{x} + C$.

**Practice 5:** Find:
a) $\int \frac{1}{x^4} dx$;
b) $\int x\sqrt{x} dx$ ($x > 0$);
c) $\int \left(\frac{3}{x} - 5\sqrt[3]{x}\right) dx$ ($x > 0$).

Solution to Practice 5:
• a) $\int \frac{1}{x^4} dx = \int x^{-4} dx = \frac{x^{-3}}{-3} + C = -\frac{1}{3x^3} + C$.
• b) $\int x\sqrt{x} dx = \int x \cdot x^{1/2} dx = \int x^{3/2} dx = \frac{x^{5/2}}{5/2} + C = \frac{2}{5}x^2\sqrt{x} + C$.
• c) For $x > 0$:
  $$\int \left(\frac{3}{x} - 5\sqrt[3]{x}\right) dx = 3\int \frac{1}{x} dx - 5\int x^{1/3} dx = 3\ln x - 5 \cdot \frac{x^{4/3}}{4/3} + C = 3\ln x - \frac{15}{4}x\sqrt[3]{x} + C.$$

### b) Antiderivatives of Trigonometric Functions

• $\int \cos x dx = \sin x + C$
• $\int \sin x dx = -\cos x + C$
• $\int \frac{1}{\cos^2 x} dx = \tan x + C$
• $\int \frac{1}{\sin^2 x} dx = -\cot x + C$

**Example 7:** Find:
a) $\int (\cos x + \sin x) dx$;
b) $\int \left(2\cos x - \frac{1}{\cos^2 x}\right) dx$.

Solution to Example 7:
• a) $\int (\cos x + \sin x) dx = \int \cos x dx + \int \sin x dx = \sin x - \cos x + C$.
• b) $\int \left(2\cos x - \frac{1}{\cos^2 x}\right) dx = 2\int \cos x dx - \int \frac{1}{\cos^2 x} dx = 2\sin x - \tan x + C$.

**Practice 6:** Find:
a) $\int (3\cos x - 4\sin x) dx$;
b) $\int \left(\frac{1}{\cos^2 x} - \frac{1}{\sin^2 x}\right) dx$.

Solution to Practice 6:
• a) $\int (3\cos x - 4\sin x) dx = 3\sin x - 4(-\cos x) + C = 3\sin x + 4\cos x + C$.
• b) $\int \left(\frac{1}{\cos^2 x} - \frac{1}{\sin^2 x}\right) dx = \tan x - (-\cot x) + C = \tan x + \cot x + C$.

### c) Antiderivatives of Exponential Functions

• $\int e^x dx = e^x + C$
• $\int a^x dx = \frac{a^x}{\ln a} + C \quad (0 < a \ne 1)$

**Example 8:** Find:
a) $\int 2^x dx$;
b) $\int \frac{1}{3^x} dx$;
c) $\int (2e^x - 5^x) dx$.

Solution to Example 8:
• a) $\int 2^x dx = \frac{2^x}{\ln 2} + C$.
• b) $\int \frac{1}{3^x} dx = \int \left(\frac{1}{3}\right)^x dx = \frac{(1/3)^x}{\ln(1/3)} + C = -\frac{1}{3^x \ln 3} + C$.
• c) $\int (2e^x - 5^x) dx = 2\int e^x dx - \int 5^x dx = 2e^x - \frac{5^x}{\ln 5} + C$.

**Practice 7:** Find:
a) $\int 4^x dx$;
b) $\int \frac{1}{e^x} dx$;
c) $\int \left(2 \cdot 3^x - \frac{1}{3} \cdot 7^x\right) dx$.

Solution to Practice 7:
• a) $\int 4^x dx = \frac{4^x}{\ln 4} + C$.
• b) $\int \frac{1}{e^x} dx = \int e^{-x} dx = -e^{-x} + C = -\frac{1}{e^x} + C$.
• c) $\int \left(2 \cdot 3^x - \frac{1}{3} \cdot 7^x\right) dx = 2 \cdot \frac{3^x}{\ln 3} - \frac{1}{3} \cdot \frac{7^x}{\ln 7} + C = \frac{2 \cdot 3^x}{\ln 3} - \frac{7^x}{3\ln 7} + C$.

## Applications and Exercises

### a) Real-World Applications

**Application 1 (Distance Traveled during Takeoff Roll):** An airplane starts its takeoff roll along a runway with velocity $v(t) = 5 + 3t\text{ (m/s)}$, where $t$ is measured in seconds from the beginning of the roll. The airplane takes off after 30 seconds. Calculate the total distance traveled by the airplane from the start of the roll until liftoff.

Solution to Application 1:
• Let $S(t)$ be the distance traveled by the airplane after $t$ seconds ($0 \le t \le 30$).
• By the physical interpretation of the derivative, $S'(t) = v(t) = 5 + 3t$. Therefore:
  $$S(t) = \int v(t) dt = \int (5 + 3t) dt = 5t + \frac{3}{2}t^2 + C.$$
• At the initial instant $t = 0$, the distance is $S(0) = 0 \implies 5(0) + \frac{3}{2}(0)^2 + C = 0 \implies C = 0$.
• Hence, the position function is $S(t) = \frac{3}{2}t^2 + 5t\text{ (m)}$.
• At liftoff ($t = 30\text{ s}$), the distance traveled is:
  $$S(30) = \frac{3}{2} \cdot 30^2 + 5 \cdot 30 = \frac{3}{2} \cdot 900 + 150 = 1\\,350 + 150 = 1\\,500\text{ (m)}.$$
• Thus, the airplane travels a total distance of $1\\,500\text{ m}$.

**Application 2 (Total Revenue from Marginal Revenue):** A company's sales revenue from selling $x$ units of a product is $R(x)$ (million VND). The marginal revenue rate is given by $M_R(x) = R'(x) = 300 - 0.2x$. Find the company's total revenue when $1\\,000$ computer chips have been sold.

Solution to Application 2:
• Total revenue $R(x)$ is an antiderivative of the marginal revenue function $M_R(x)$:
  $$R(x) = \int M_R(x) dx = \int (300 - 0.2x) dx = 300x - 0.1x^2 + C.$$
• When no units are sold ($x = 0$), the revenue is zero: $R(0) = 0 \implies C = 0$.
• Hence, the revenue function is $R(x) = 300x - 0.1x^2\text{ (million VND)}$.
• For $x = 1\\,000$ chips:
  $$R(1\\,000) = 300(1\\,000) - 0.1(1\\,000)^2 = 300\\,000 - 100\\,000 = 200\\,000\text{ (million VND)}.$$
• Thus, the total revenue upon selling $1\\,000$ chips is $200\\,000$ million VND (or 200 billion VND).

### b) End-of-Lesson Exercises

**Exercise 4.1:** In each of the following cases, determine whether the function $F(x)$ is an antiderivative of the function $f(x)$ on the corresponding interval. Explain why.
a) $F(x) = x\ln x$ and $f(x) = 1 + \ln x$ on $(0; +\infty)$;
b) $F(x) = e^{\sin x}$ and $f(x) = e^{\cos x}$ on $\mathbb{R}$.

Solution to Exercise 4.1:
• a) For all $x \in (0; +\infty)$, applying the product rule for differentiation:
  $$F'(x) = (x\ln x)' = (x)' \ln x + x(\ln x)' = 1 \cdot \ln x + x \cdot \frac{1}{x} = \ln x + 1 = f(x).$$
  Therefore, $F(x)$ is an antiderivative of $f(x)$ on $(0; +\infty)$.
• b) For all $x \in \mathbb{R}$, by the chain rule:
  $$F'(x) = (e^{\sin x})' = (\sin x)' \cdot e^{\sin x} = \cos x \cdot e^{\sin x}.$$
  We observe that $F'(x) = \cos x \cdot e^{\sin x} \ne e^{\cos x} = f(x)$ (for example, at $x = 0$, $F'(0) = 1 \ne e^1 = f(0)$).
  Hence, $F(x)$ is not an antiderivative of $f(x)$ on $\mathbb{R}$.

**Exercise 4.2:** Find the antiderivatives of the following functions:
a) $f(x) = 3x^2 + 2x - 1$;
b) $f(x) = x^3 - x$;
c) $f(x) = (2x + 1)^2$;
d) $f(x) = \left(2x - \frac{1}{x}\right)^2$.

Solution to Exercise 4.2:
• a) $\int (3x^2 + 2x - 1) dx = 3 \cdot \frac{x^3}{3} + 2 \cdot \frac{x^2}{2} - x + C = x^3 + x^2 - x + C$.
• b) $\int (x^3 - x) dx = \frac{x^4}{4} - \frac{x^2}{2} + C$.
• c) $\int (2x + 1)^2 dx = \int (4x^2 + 4x + 1) dx = \frac{4}{3}x^3 + 2x^2 + x + C$.
• d) Expanding the integrand:
  $$\int \left(2x - \frac{1}{x}\right)^2 dx = \int \left(4x^2 - 4 + \frac{1}{x^2}\right) dx = \frac{4}{3}x^3 - 4x - \frac{1}{x} + C.$$

**Exercise 4.3:** Find:
a) $\int \left(3\sqrt{x} + \frac{1}{\sqrt[3]{x}}\right) dx$;
b) $\int \sqrt{x}(7x^2 - 3) dx$ ($x > 0$);
c) $\int \frac{(2x + 1)^2}{x^2} dx$;
d) $\int \left(2^x + \frac{3}{x^2}\right) dx$.

Solution to Exercise 4.3:
• a) $\int (3x^{1/2} + x^{-1/3}) dx = 3 \cdot \frac{x^{3/2}}{3/2} + \frac{x^{2/3}}{2/3} + C = 2x\sqrt{x} + \frac{3}{2}\sqrt[3]{x^2} + C$.
• b) $\int \sqrt{x}(7x^2 - 3) dx = \int (7x^{5/2} - 3x^{1/2}) dx = 7 \cdot \frac{x^{7/2}}{7/2} - 3 \cdot \frac{x^{3/2}}{3/2} + C = 2x^3\sqrt{x} - 2x\sqrt{x} + C$.
• c) $\int \frac{4x^2 + 4x + 1}{x^2} dx = \int \left(4 + \frac{4}{x} + \frac{1}{x^2}\right) dx = 4x + 4\ln |x| - \frac{1}{x} + C$.
• d) $\int \left(2^x + \frac{3}{x^2}\right) dx = \frac{2^x}{\ln 2} - \frac{3}{x} + C$.

**Exercise 4.4:** Find:
a) $\int \left(2\cos x - \frac{3}{\sin^2 x}\right) dx$;
b) $\int 4\sin^2 \frac{x}{2} dx$;
c) $\int \left(\sin \frac{x}{2} - \cos \frac{x}{2}\right)^2 dx$;
d) $\int (x + \tan^2 x) dx$.

Solution to Exercise 4.4:
• a) $\int \left(2\cos x - \frac{3}{\sin^2 x}\right) dx = 2\sin x - 3(-\cot x) + C = 2\sin x + 3\cot x + C$.
• b) Using the power-reduction formula: $4\sin^2 \frac{x}{2} = 4 \cdot \frac{1 - \cos x}{2} = 2 - 2\cos x$.
  $$\int 4\sin^2 \frac{x}{2} dx = \int (2 - 2\cos x) dx = 2x - 2\sin x + C.$$
• c) Expanding the squared trigonometric expression:
  $$\left(\sin \frac{x}{2} - \cos \frac{x}{2}\right)^2 = \sin^2 \frac{x}{2} - 2\sin \frac{x}{2}\cos \frac{x}{2} + \cos^2 \frac{x}{2} = 1 - \sin x.$$
  $$\int \left(\sin \frac{x}{2} - \cos \frac{x}{2}\right)^2 dx = \int (1 - \sin x) dx = x - (-\cos x) + C = x + \cos x + C.$$
• d) Rewriting $\tan^2 x = (\tan^2 x + 1) - 1 = \frac{1}{\cos^2 x} - 1$:
  $$\int (x + \tan^2 x) dx = \int \left(x - 1 + \frac{1}{\cos^2 x}\right) dx = \frac{x^2}{2} - x + \tan x + C.$$

**Exercise 4.5:** Let the function $y = f(x)$ be defined on $(0; +\infty)$. Given that $f'(x) = 2x + \frac{1}{x^2}$ for all $x \in (0; +\infty)$ and $f(1) = 1$. Calculate the value $f(4)$.

Solution to Exercise 4.5:
• Since $f(x)$ is an antiderivative of $f'(x)$ on $(0; +\infty)$:
  $$f(x) = \int f'(x) dx = \int \left(2x + \frac{1}{x^2}\right) dx = x^2 - \frac{1}{x} + C.$$
• From the condition $f(1) = 1 \implies 1^2 - \frac{1}{1} + C = 1 \iff 0 + C = 1 \implies C = 1$.
• Thus: $f(x) = x^2 - \frac{1}{x} + 1$.
• Therefore, the value of $f(4)$ is:
  $$f(4) = 4^2 - \frac{1}{4} + 1 = 16 - 0.25 + 1 = 16.75 = \frac{67}{4}.$$

**Exercise 4.6:** Given the curve $(C): y = f(x)$. Suppose that the slope of the tangent line to $(C)$ at any point $M(x; f(x))$ is $k_M = (x - 1)^2$, and $M$ coincides with the origin when it lies on the y-axis. Find the expression of $f(x)$.

Solution to Exercise 4.6:
• The slope of the tangent line at abscissa $x$ is given by $f'(x)$, so:
  $$f'(x) = k_M = (x - 1)^2 = x^2 - 2x + 1.$$
• The function $f(x)$ is the antiderivative of $f'(x)$:
  $$f(x) = \int (x^2 - 2x + 1) dx = \frac{x^3}{3} - x^2 + x + C.$$
• When $M$ lies on the y-axis, its abscissa is $x = 0$. Given that it coincides with the origin $O(0; 0)$, we have $f(0) = 0$:
  $$f(0) = \frac{0^3}{3} - 0^2 + 0 + C = 0 \implies C = 0.$$
• Hence, the required expression is $f(x) = \frac{x^3}{3} - x^2 + x$.

**Exercise 4.7:** A projectile is fired vertically upward from ground level. Its velocity at time $t$ seconds ($t = 0$ at launch) is given by $v(t) = 160 - 9.8t\text{ (m/s)}$. Find the height of the projectile above ground level:
a) After $t = 5$ seconds;
b) When it reaches its maximum height (round the result to one decimal place).

Solution to Exercise 4.7:
• Let $h(t)$ be the height of the projectile above the ground at time $t$. Since $h'(t) = v(t) = 160 - 9.8t$, we have:
  $$h(t) = \int v(t) dt = \int (160 - 9.8t) dt = 160t - 4.9t^2 + C.$$
• At the moment of launch from ground level $t = 0$, $h(0) = 0 \implies C = 0$.
  Thus, the height equation is $h(t) = 160t - 4.9t^2\text{ (m)}$.
• a) After $t = 5$ seconds, the height is:
  $$h(5) = 160(5) - 4.9(5^2) = 800 - 4.9 \cdot 25 = 800 - 122.5 = 677.5\text{ (m)}.$$
• b) The projectile reaches its maximum height when its instantaneous velocity becomes zero ($v(t) = 0$):
  $$160 - 9.8t = 0 \iff t = \frac{160}{9.8} = \frac{800}{49} \approx 16.327\text{ (seconds)}.$$
• The maximum height attained is:
  $$h\_{\max} = 160 \cdot \left(\frac{800}{49}\right) - 4.9 \cdot \left(\frac{800}{49}\right)^2 = \frac{128\\,000}{49} - \frac{64\\,000}{49} = \frac{64\\,000}{49} \approx 1\\,306.1\text{ (m)}.$$
• Therefore, the projectile reaches a maximum height of approximately $1\\,306.1\text{ m}$.
