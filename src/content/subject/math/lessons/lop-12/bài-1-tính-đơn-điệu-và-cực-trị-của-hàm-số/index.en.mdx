## Lesson Objectives

## Monotonicity of a Function

\<Youtube url="https://www.youtube.com/watch?v=example_tinh_don_dieu_ham_so"/>

### a) Concept of Monotonicity and Relationship with the Sign of the Derivative

Let $K$ be an interval, a segment, or a half-interval, and let $y = f(x)$ be a function defined on $K$.
• The function $y = f(x)$ is said to be increasing (strictly increasing) on $K$ if:
$$\forall x_1, x_2 \in K, x_1 < x_2 \implies f(x_1) < f(x_2)$$
• The function $y = f(x)$ is said to be decreasing (strictly decreasing) on $K$ if:
$$\forall x_1, x_2 \in K, x_1 < x_2 \implies f(x_1) > f(x_2)$$
• The graph of an increasing function rises from left to right; the graph of a decreasing function falls from left to right.
Theorem (Sign of the Derivative and Monotonicity): Let the function $y = f(x)$ be differentiable on an interval $K$.
\- If $f'(x) > 0$ for all $x \in K$, then the function $f(x)$ is increasing on the interval $K$.
\- If $f'(x) < 0$ for all $x \in K$, then the function $f(x)$ is decreasing on the interval $K$.
\- Extension: If $f'(x) \ge 0$ ($f'(x) \le 0$) for all $x \in K$ and $f'(x) = 0$ at only a finite number of points in $K$, then the function $f(x)$ is increasing (decreasing) on the interval $K$.
\- If $f'(x) = 0$ for all $x \in K$, then the function $f(x)$ is constant on the interval $K$.

### b) Procedure for Determining Monotonicity Using a Table of Variations

Procedure for investigating the monotonicity of a function $y = f(x)$:
1\. Find the domain of the function;
2\. Compute the derivative $f'(x)$. Find the points $x_i$ where $f'(x) = 0$ or where the derivative does not exist;
3\. Arrange the points $x_i$ in ascending order and construct the table of variations showing the sign of $f'(x)$;
4\. Conclude the intervals where the function is increasing and decreasing.

**Example 2:** Find the intervals of increase and decrease for the function $y = x^2 - 4x + 2$.

Solution to Example 2:
• Domain: $D = \mathbb{R}$.
• Derivative: $y' = 2x - 4$. We have $y' = 0 \iff 2x - 4 = 0 \iff x = 2$.
• Sign of the derivative: $y' > 0$ when $x \in (2; +\infty)$ and $y' < 0$ when $x \in (-\infty; 2)$.
• Thus, the function is increasing on the interval $(2; +\infty)$ and decreasing on the interval $(-\infty; 2)$.

**Example 3:** Find the intervals of monotonicity of the function $y = \frac{x^2 - 2x + 5}{x - 1}$.

Solution to Example 3:
• Domain: $D = \mathbb{R} \setminus \\{1\\}$.
• Derivative:
  $$y' = \frac{(2x - 2)(x - 1) - (x^2 - 2x + 5)}{(x - 1)^2} = \frac{x^2 - 2x - 3}{(x - 1)^2}.$$
• Solving the derivative equation: $y' = 0 \iff x^2 - 2x - 3 = 0 \iff x = -1$ or $x = 3$.
• Table of variations:
  - On $(-\infty; -1)$: $y' > 0 \implies$ the function is increasing.
  - On $(-1; 1)$: $y' < 0 \implies$ the function is decreasing.
  - On $(1; 3)$: $y' < 0 \implies$ the function is decreasing.
  - On $(3; +\infty)$: $y' > 0 \implies$ the function is increasing.
• Conclusion: The function is increasing on the intervals $(-\infty; -1)$ and $(3; +\infty)$; decreasing on the intervals $(-1; 1)$ and $(1; 3)$.

**Example 4:** Determine the monotonicity of the function $y = \frac{x - 2}{x + 1}$.

Solution to Example 4:
• Domain: $D = \mathbb{R} \setminus \\{-1\\}$.
• Derivative:
  $$y' = \frac{(x + 1) - (x - 2)}{(x + 1)^2} = \frac{3}{(x + 1)^2} > 0, \quad \forall x \ne -1.$$
• Thus, the function is increasing on each of the intervals $(-\infty; -1)$ and $(-1; +\infty)$.

## Local Extrema of a Function

\<Youtube url="https://www.youtube.com/watch?v=example_cuc_tri_ham_so"/>

### a) Concepts of Local Maximum and Local Minimum

Let the function $y = f(x)$ be defined and continuous on an open interval $(a; b)$ containing the point $x_0$.
• If there exists a number $h > 0$ such that $f(x) < f(x_0)$ for all $x \in (x_0 - h; x_0 + h) \setminus \\{x_0\\}$, then the function attains a local maximum at $x_0$.
  - $x_0$ is called a local maximum point of the function;
  - $f(x_0)$ (or $y\_{\max}$) is called the local maximum value of the function;
  - $M_0(x_0; f(x_0))$ is called the local maximum point of the function's graph.
• If there exists a number $h > 0$ such that $f(x) > f(x_0)$ for all $x \in (x_0 - h; x_0 + h) \setminus \\{x_0\\}$, then the function attains a local minimum at $x_0$.
  - $x_0$ is called a local minimum point of the function;
  - $f(x_0)$ (or $y\_{\min}$) is called the local minimum value of the function;
  - $M_0(x_0; f(x_0))$ is called the local minimum point of the function's graph.
• Local maximum points and local minimum points are collectively called local extreme points (or local extrema) of the function.

### b) Sufficient Conditions for Local Extrema and Procedure for Finding Extrema

Suppose the function $y = f(x)$ is continuous on the interval $(a; b)$ containing $x_0$ and is differentiable on $(a; x_0)$ and $(x_0; b)$:
• If $f'(x) > 0$ on $(a; x_0)$ and $f'(x) < 0$ on $(x_0; b)$ (the derivative changes sign from positive to negative as $x$ passes through $x_0$), then the function attains a local maximum at $x_0$.
• If $f'(x) < 0$ on $(a; x_0)$ and $f'(x) > 0$ on $(x_0; b)$ (the derivative changes sign from negative to positive as $x$ passes through $x_0$), then the function attains a local minimum at $x_0$.
• Note: If $f'(x)$ does not change sign as $x$ passes through $x_0$, then $x_0$ is not a local extreme point of the function (for example, $y = x^3$ has $y' = 3x^2 \ge 0$ and $y'(0) = 0$, but has no local extrema).

**Example 6:** Find the local extrema of the function $y = x^3 - 6x^2 + 9x + 30$.

Solution to Example 6:
• Domain: $D = \mathbb{R}$.
• Derivative: $y' = 3x^2 - 12x + 9 = 3(x - 1)(x - 3)$.
• Set $y' = 0 \iff x = 1$ or $x = 3$.
• Sign analysis:
  - As $x$ passes through $x = 1$, $y'$ changes sign from positive to negative $\implies$ the function attains a local maximum at $x = 1$, with local maximum value $y\_{\max} = y(1) = 34$.
  - As $x$ passes through $x = 3$, $y'$ changes sign from negative to positive $\implies$ the function attains a local minimum at $x = 3$, with local minimum value $y\_{\min} = y(3) = 30$.

**Example 7:** Find the local extrema of the function $y = \frac{x^2 - 2x + 9}{x - 2}$.

Solution to Example 7:
• Domain: $D = \mathbb{R} \setminus \\{2\\}$.
• Derivative:
  $$y' = \frac{(2x - 2)(x - 2) - (x^2 - 2x + 9)}{(x - 2)^2} = \frac{x^2 - 4x - 5}{(x - 2)^2}.$$
• $y' = 0 \iff x^2 - 4x - 5 = 0 \iff x = -1$ or $x = 5$.
• Sign analysis:
  - As $x$ passes through $x = -1$, $y'$ changes sign from positive to negative $\implies$ the function attains a local maximum at $x = -1$, with local maximum value $y\_{\max} = y(-1) = -4$.
  - As $x$ passes through $x = 5$, $y'$ changes sign from negative to positive $\implies$ the function attains a local minimum at $x = 5$, with local minimum value $y\_{\min} = y(5) = 8$.

## Applications and Exercises

### a) Real-World Applications

**Application 1 (Motion of a Particle):** The position of a particle on a horizontal axis at time $t$ seconds ($t \ge 0$) is given by $s(t) = t^3 - 9t^2 + 15t$ (meters). During which time intervals is the particle moving to the right (positive direction), and during which is it moving to the left?

Solution to Application 1:
• The instantaneous velocity of the particle at time $t$ is:
  $$v(t) = s'(t) = 3t^2 - 18t + 15 = 3(t - 1)(t - 5).$$
• The particle moves to the right when $v(t) > 0 \iff t \in [0; 1) \cup (5; +\infty)$.
• The particle moves to the left when $v(t) < 0 \iff t \in (1; 5)$.
• Thus, the particle moves to the right for $t \in [0; 1)$ and $t > 5$; it moves to the left for $t \in (1; 5)$.

**Application 2 (Maximum Height of a Vertical Projectile):** An object is launched vertically upward from a height of 2 m with an initial velocity $v_0 = 24.5\text{ m/s}$. Its height after $t$ seconds is $h(t) = 2 + 24.5t - 4.9t^2$ (meters). At what time does the object reach its maximum height?

Solution to Application 2:
• The velocity of the object at time $t$ is: $v(t) = h'(t) = 24.5 - 9.8t$.
• Setting $h'(t) = 0 \iff 24.5 - 9.8t = 0 \iff t = \frac{24.5}{9.8} = 2.5\text{ (seconds)}$.
• Since $h'(t)$ changes sign from positive to negative as $t$ passes through $2.5$, the function attains its maximum at $t = 2.5$.
• The maximum height attained is $h(2.5) = 2 + 24.5(2.5) - 4.9(2.5)^2 = 32.625\text{ m}$.
• Therefore, the object reaches its maximum height 2.5 seconds after launch.

**Logistic Growth Model (Product Sales):** The sales volume of a new product follows the logistic model $f(t) = \frac{5\\,000}{1 + 5e^{-t}}$ ($t \ge 0$, in years). The rate of sales is given by the derivative $f'(t)$. After how many years is the rate of sales maximized?

Solution:
• Let $u = 1 + 5e^{-t}$, then:
  $$f'(t) = 5\\,000 \cdot \frac{-(1 + 5e^{-t})'}{(1 + 5e^{-t})^2} = \frac{25\\,000 e^{-t}}{(1 + 5e^{-t})^2}.$$
• To maximize $f'(t)$, consider the second derivative $f''(t)$:
  $$f''(t) = 25\\,000 \cdot \frac{-e^{-t}(1 + 5e^{-t})^2 - e^{-t} \cdot 2(1 + 5e^{-t})(-5e^{-t})}{(1 + 5e^{-t})^4} = \frac{25\\,000 e^{-t}(5e^{-t} - 1)}{(1 + 5e^{-t})^3}.$$
• Setting $f''(t) = 0 \iff 5e^{-t} - 1 = 0 \iff e^t = 5 \iff t = \ln 5 \approx 1.61\text{ (years)}$.
• As $t$ passes through $\ln 5$, $f''(t)$ changes sign from positive to negative; hence the sales rate $f'(t)$ achieves a maximum at $t = \ln 5$.
• Therefore, after approximately 1.61 years (about 1 year and 7 months), the sales rate is maximized.

### b) End-of-Lesson Exercises

**Exercise 1.2:** Investigate the intervals of increase and decrease for the following functions:
a) $y = \frac{1}{3}x^3 - 2x^2 + 3x + 1$;
b) $y = -x^3 + 2x^2 - 5x + 3$.

Solution to Exercise 1.2:
• a) Domain: $D = \mathbb{R}$.
  Derivative: $y' = x^2 - 4x + 3 = (x - 1)(x - 3)$.
  $y' = 0 \iff x = 1$ or $x = 3$.
  Sign of $y'$: $y' > 0$ for $x \in (-\infty; 1) \cup (3; +\infty)$; $y' < 0$ for $x \in (1; 3)$.
  Conclusion: The function is increasing on $(-\infty; 1)$ and $(3; +\infty)$; decreasing on $(1; 3)$.
• b) Domain: $D = \mathbb{R}$.
  Derivative: $y' = -3x^2 + 4x - 5$.
  Discriminant $\Delta' = 2^2 - (-3)(-5) = 4 - 15 = -11 < 0$ and leading coefficient $a = -3 < 0$.
  Therefore, $y' < 0$ for all $x \in \mathbb{R}$.
  Conclusion: The function is decreasing on $\mathbb{R}$.

**Exercise 1.3:** Find the intervals of monotonicity for the following functions:
a) $y = \frac{2x - 1}{x + 2}$;
b) $y = \frac{x^2 + x + 4}{x - 3}$.

Solution to Exercise 1.3:
• a) Domain: $D = \mathbb{R} \setminus \\{-2\\}$.
  Derivative: $y' = \frac{2(x + 2) - (2x - 1)}{(x + 2)^2} = \frac{5}{(x + 2)^2} > 0, \forall x \ne -2$.
  Conclusion: The function is increasing on each interval $(-\infty; -2)$ and $(-2; +\infty)$.
• b) Domain: $D = \mathbb{R} \setminus \\{3\\}$.
  Derivative:
  $$y' = \frac{(2x + 1)(x - 3) - (x^2 + x + 4)}{(x - 3)^2} = \frac{x^2 - 6x - 7}{(x - 3)^2}.$$
  $y' = 0 \iff x^2 - 6x - 7 = 0 \iff x = -1$ or $x = 7$.
  Conclusion: The function is increasing on $(-\infty; -1)$ and $(7; +\infty)$; decreasing on $(-1; 3)$ and $(3; 7)$.

**Exercise 1.7:** Find the local extrema of the following functions:
a) $y = 2x^3 - 9x^2 + 12x - 5$;
b) $y = x^4 - 4x^2 + 2$;
c) $y = \frac{x^2 - 2x + 3}{x - 1}$.

Solution to Exercise 1.7:
• a) $D = \mathbb{R}$. $y' = 6x^2 - 18x + 12 = 6(x - 1)(x - 2)$.
  $y' = 0 \iff x = 1$ or $x = 2$.
  The function attains a local maximum at $x = 1$ with $y\_{\max} = y(1) = 0$.
  The function attains a local minimum at $x = 2$ with $y\_{\min} = y(2) = -1$.
• b) $D = \mathbb{R}$. $y' = 4x^3 - 8x = 4x(x^2 - 2)$.
  $y' = 0 \iff x = 0$ or $x = \pm\sqrt{2}$.
  The function attains a local maximum at $x = 0$ with $y\_{\max} = y(0) = 2$.
  The function attains local minima at $x = \pm\sqrt{2}$ with $y\_{\min} = y(\pm\sqrt{2}) = -2$.
• c) $D = \mathbb{R} \setminus \\{1\\}$.
  $$y' = \frac{(2x - 2)(x - 1) - (x^2 - 2x + 3)}{(x - 1)^2} = \frac{x^2 - 2x - 1}{(x - 1)^2}.$$
  $y' = 0 \iff x^2 - 2x - 1 = 0 \iff x = 1 - \sqrt{2}$ or $x = 1 + \sqrt{2}$.
  The function attains a local maximum at $x = 1 - \sqrt{2}$ with $y\_{\max} = 2 - 2\sqrt{2}$.
  The function attains a local minimum at $x = 1 + \sqrt{2}$ with $y\_{\min} = 2 + 2\sqrt{2}$.
