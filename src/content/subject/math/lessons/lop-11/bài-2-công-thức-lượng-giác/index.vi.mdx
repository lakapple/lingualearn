·       Công thức cộng

### **Kiến thức, kĩ năng:**

·       Mô tả thành thạo các phép biến đổi lượng giác cơ bản: công thức cộng, công thức góc nhân đôi, công thức hạ bậc, công thức biến đổi tích thành tổng và công thức biến đổi tổng thành tích.

## Công thức cộng

<Youtube url="https://www.youtube.com/watch?v=example_cong_thuc_cong"/>

### a) Nội dung công thức cộng

Các công thức cộng cơ bản:
• $\cos(a - b) = \cos a \cos b + \sin a \sin b$
• $\cos(a + b) = \cos a \cos b - \sin a \sin b$
• $\sin(a - b) = \sin a \cos b - \cos a \sin b$
• $\sin(a + b) = \sin a \cos b + \cos a \sin b$
• $\tan(a - b) = \frac{\tan a - \tan b}{1 + \tan a \tan b} \quad \left(a, b, a - b \ne \frac{\pi}{2} + k\pi\right)$
• $\tan(a + b) = \frac{\tan a + \tan b}{1 - \tan a \tan b} \quad \left(a, b, a + b \ne \frac{\pi}{2} + k\pi\right)$

### b) Ví dụ và luyện tập công thức cộng

**Ví dụ 1:** Không dùng máy tính, hãy tính:
a) $\cos 75^{\circ}$;
b) $\tan\frac{\pi}{12}$.

Lời giải Ví dụ 1:
• a) $\cos 75^{\circ} = \cos(45^{\circ} + 30^{\circ}) = \cos 45^{\circ}\cos 30^{\circ} - \sin 45^{\circ}\sin 30^{\circ} = \frac{\sqrt{2}}{2} \cdot \frac{\sqrt{3}}{2} - \frac{\sqrt{2}}{2} \cdot \frac{1}{2} = \frac{\sqrt{6} - \sqrt{2}}{4}$.
• b) $\tan\frac{\pi}{12} = \tan\left(\frac{\pi}{3} - \frac{\pi}{4}\right) = \frac{\tan\frac{\pi}{3} - \tan\frac{\pi}{4}}{1 + \tan\frac{\pi}{3}\tan\frac{\pi}{4}} = \frac{\sqrt{3} - 1}{1 + \sqrt{3}} = (\sqrt{3} - 1)^2 = 2 - \sqrt{3}$.

**Ví dụ 2:** Chứng minh rằng $\sin x + \cos x = \sqrt{2}\sin\left(x + \frac{\pi}{4}\right)$.

Lời giải Ví dụ 2:
• Ta có $\sqrt{2}\sin\left(x + \frac{\pi}{4}\right) = \sqrt{2}\left(\sin x \cos\frac{\pi}{4} + \cos x \sin\frac{\pi}{4}\right) = \sqrt{2}\left(\sin x \cdot \frac{\sqrt{2}}{2} + \cos x \cdot \frac{\sqrt{2}}{2}\right) = \sin x + \cos x$.
Đẳng thức được chứng minh.

**Luyện tập 1:** Chứng minh rằng:
a) $\sin x - \cos x = \sqrt{2}\sin\left(x - \frac{\pi}{4}\right)$;
b) $\tan\left(\frac{\pi}{4} - x\right) = \frac{1 - \tan x}{1 + \tan x} \quad \left(x \ne \frac{\pi}{2} + k\pi, x \ne \frac{3\pi}{4} + k\pi\right)$.

Lời giải Luyện tập 1:
• a) $\sqrt{2}\sin\left(x - \frac{\pi}{4}\right) = \sqrt{2}\left(\sin x \cos\frac{\pi}{4} - \cos x \sin\frac{\pi}{4}\right) = \sqrt{2}\left(\sin x \cdot \frac{\sqrt{2}}{2} - \cos x \cdot \frac{\sqrt{2}}{2}\right) = \sin x - \cos x$.
• b) $\tan\left(\frac{\pi}{4} - x\right) = \frac{\tan\frac{\pi}{4} - \tan x}{1 + \tan\frac{\pi}{4}\tan x} = \frac{1 - \tan x}{1 + \tan x}$.

## Công thức nhân đôi và hạ bậc

<Youtube url="https://www.youtube.com/watch?v=example_cong_thuc_nhan_doi"/>

### a) Công thức nhân đôi

Các công thức nhân đôi (đặt $b = a$ trong công thức cộng):
• $\sin 2a = 2\sin a \cos a$
• $\cos 2a = \cos^2 a - \sin^2 a = 2\cos^2 a - 1 = 1 - 2\sin^2 a$
• $\tan 2a = \frac{2\tan a}{1 - \tan^2 a} \quad \left(a \ne \frac{\pi}{4} + \frac{k\pi}{2}, a \ne \frac{\pi}{2} + k\pi\right)$
Công thức hạ bậc:
• $\cos^2 a = \frac{1 + \cos 2a}{2}$
• $\sin^2 a = \frac{1 - \cos 2a}{2}$

### b) Ví dụ và luyện tập công thức nhân đôi

**Ví dụ 3:** Cho $\cos a = -\frac{1}{3}$ với $\frac{\pi}{2} < a < \pi$. Tính $\sin 2a$.

Lời giải Ví dụ 3:
• Vì $\frac{\pi}{2} < a < \pi$ nên $\sin a > 0$ và $\cos a < 0$.
• Ta có $\sin a = \sqrt{1 - \cos^2 a} = \sqrt{1 - \left(-\frac{1}{3}\right)^2} = \sqrt{1 - \frac{1}{9}} = \frac{2\sqrt{2}}{3}$.
• Vậy $\sin 2a = 2\sin a \cos a = 2 \cdot \frac{2\sqrt{2}}{3} \cdot \left(-\frac{1}{3}\right) = -\frac{4\sqrt{2}}{9}$.

**Luyện tập 2:** Không dùng máy tính, tính $\cos\frac{\pi}{8}$.

Lời giải Luyện tập 2:
• Áp dụng công thức hạ bậc với $a = \frac{\pi}{8} \Rightarrow 2a = \frac{\pi}{4}$:
$$\cos^2\frac{\pi}{8} = \frac{1 + \cos\frac{\pi}{4}}{2} = \frac{1 + \frac{\sqrt{2}}{2}}{2} = \frac{2 + \sqrt{2}}{4}$$
• Vì $\frac{\pi}{8}$ thuộc góc phần tư thứ nhất nên $\cos\frac{\pi}{8} > 0$, suy ra $\cos\frac{\pi}{8} = \frac{\sqrt{2 + \sqrt{2}}}{2}$.

## Công thức biến đổi tích thành tổng

<Youtube url="https://www.youtube.com/watch?v=example_tich_thanh_tong"/>

### a) Nội dung công thức tích thành tổng

Các công thức biến đổi tích thành tổng:
• $\cos a \cos b = \frac{1}{2}[\cos(a - b) + \cos(a + b)]$
• $\sin a \sin b = \frac{1}{2}[\cos(a - b) - \cos(a + b)]$
• $\sin a \cos b = \frac{1}{2}[\sin(a - b) + \sin(a + b)]
$

### b) Ví dụ và luyện tập biến đổi tích thành tổng

**Ví dụ 4:** Tính giá trị của các biểu thức:
a) $A = \cos\frac{5\pi}{12} \cos\frac{7\pi}{12}$;
b) $B = \cos 75^{\circ} \sin 15^{\circ}$.

Lời giải Ví dụ 4:
• a) $A = \cos\frac{5\pi}{12}\cos\frac{7\pi}{12} = \frac{1}{2}\left[\cos\left(\frac{5\pi}{12} - \frac{7\pi}{12}\right) + \cos\left(\frac{5\pi}{12} + \frac{7\pi}{12}\right)\right] = \frac{1}{2}[\cos(-\frac{\pi}{6}) + \cos\pi] = \frac{1}{2}\left(\frac{\sqrt{3}}{2} - 1\right) = \frac{\sqrt{3} - 2}{4}$.
• b) $B = \sin 15^{\circ}\cos 75^{\circ} = \frac{1}{2}[\sin(15^{\circ} - 75^{\circ}) + \sin(15^{\circ} + 75^{\circ})] = \frac{1}{2}[\sin(-60^{\circ}) + \sin 90^{\circ}] = \frac{1}{2}\left(-\frac{\sqrt{3}}{2} + 1\right) = \frac{2 - \sqrt{3}}{4}$.

**Luyện tập 3:** Không dùng máy tính, tính giá trị của các biểu thức:
a) $A = \cos 75^{\circ} \cos 15^{\circ}$;
b) $B = \sin\frac{5\pi}{12} \cos\frac{7\pi}{12}$.

Lời giải Luyện tập 3:
• a) $A = \cos 75^{\circ}\cos 15^{\circ} = \frac{1}{2}[\cos(75^{\circ} - 15^{\circ}) + \cos(75^{\circ} + 15^{\circ})] = \frac{1}{2}(\cos 60^{\circ} + \cos 90^{\circ}) = \frac{1}{2}\left(\frac{1}{2} + 0\right) = \frac{1}{4}$.
• b) $B = \sin\frac{5\pi}{12}\cos\frac{7\pi}{12} = \frac{1}{2}\left[\sin\left(\frac{5\pi}{12} - \frac{7\pi}{12}\right) + \sin\left(\frac{5\pi}{12} + \frac{7\pi}{12}\right)\right] = \frac{1}{2}[\sin(-\frac{\pi}{6}) + \sin\pi] = \frac{1}{2}\left(-\frac{1}{2} + 0\right) = -\frac{1}{4}$.

## Công thức biến đổi tổng thành tích

<Youtube url="https://www.youtube.com/watch?v=example_tong_thanh_tich"/>

### a) Nội dung công thức tổng thành tích

Các công thức biến đổi tổng thành tích (đặt $u = a - b, v = a + b$ hoặc ngược lại):
• $\cos u + \cos v = 2\cos\frac{u + v}{2} \cos\frac{u - v}{2}$
• $\cos u - \cos v = -2\sin\frac{u + v}{2} \sin\frac{u - v}{2}$
• $\sin u + \sin v = 2\sin\frac{u + v}{2} \cos\frac{u - v}{2}$
• $\sin u - \sin v = 2\cos\frac{u + v}{2} \sin\frac{u - v}{2}$

### b) Ví dụ và luyện tập tổng thành tích

**Ví dụ 5:** Không dùng máy tính, tính giá trị của biểu thức $A = \sin\frac{\pi}{9} - \sin\frac{4\pi}{9} + \sin\frac{7\pi}{9}$.

Lời giải Ví dụ 5:
• $A = \left(\sin\frac{\pi}{9} + \sin\frac{7\pi}{9}\right) - \sin\frac{4\pi}{9} = 2\sin\frac{\frac{\pi}{9} + \frac{7\pi}{9}}{2}\cos\frac{\frac{\pi}{9} - \frac{7\pi}{9}}{2} - \sin\frac{4\pi}{9} = 2\sin\frac{4\pi}{9}\cos\left(-\frac{\pi}{3}\right) - \sin\frac{4\pi}{9} = 2\sin\frac{4\pi}{9} \cdot \frac{1}{2} - \sin\frac{4\pi}{9} = \sin\frac{4\pi}{9} - \sin\frac{4\pi}{9} = 0$.

**Luyện tập 4:** Không dùng máy tính, tính giá trị của biểu thức $B = \cos\frac{\pi}{9} + \cos\frac{5\pi}{9} + \cos\frac{11\pi}{9}$.

Lời giải Luyện tập 4:
• Ta có $\cos\frac{11\pi}{9} = \cos\left(2\pi - \frac{7\pi}{9}\right) = \cos\frac{7\pi}{9}$.
• Khi đó $B = \left(\cos\frac{\pi}{9} + \cos\frac{7\pi}{9}\right) + \cos\frac{5\pi}{9} = 2\cos\frac{4\pi}{9}\cos\left(-\frac{\pi}{3}\right) + \cos\frac{5\pi}{9} = 2\cos\frac{4\pi}{9} \cdot \frac{1}{2} + \cos\frac{5\pi}{9} = \cos\frac{4\pi}{9} + \cos\left(\pi - \frac{4\pi}{9}\right) = \cos\frac{4\pi}{9} - \cos\frac{4\pi}{9} = 0$.

## Ứng dụng và bài tập rèn luyện

### a) Bài toán thực tế và mô hình hoá

**Vận dụng 1 (Âm kết hợp trong thiết bị kĩ thuật số):** Thiết bị trễ lặp lại tín hiệu đầu vào $f_1(t) = 5\sin t$ và phát lại $f_2(t) = 5\cos t$. Âm kết hợp là $f(t) = f_1(t) + f_2(t)$. Biểu diễn $f(t)$ dưới dạng sóng hình sin $f(t) = k\sin(t + \varphi)$ và xác định biên độ $k$, pha ban đầu $\varphi$.

Lời giải Vận dụng 1:
• Ta có $f(t) = 5\sin t + 5\cos t = 5(\sin t + \cos t) = 5\sqrt{2}\left(\sin t \cdot \frac{\sqrt{2}}{2} + \cos t \cdot \frac{\sqrt{2}}{2}\right) = 5\sqrt{2}\left(\sin t \cos\frac{\pi}{4} + \cos t \sin\frac{\pi}{4}\right) = 5\sqrt{2}\sin\left(t + \frac{\pi}{4}\right)$.
• Biên độ sóng âm là $k = 5\sqrt{2}$, pha ban đầu là $\varphi = \frac{\pi}{4}$.

**Bài 1.13 (Dao động điều hoà tổng hợp):** Cho hai dao động điều hoà: $x_1(t) = 2\cos\left(\frac{\pi}{3}t + \frac{\pi}{6}\right)$ (cm) và $x_2(t) = 2\cos\left(\frac{\pi}{3}t - \frac{\pi}{3}\right)$ (cm). Tìm dao động tổng hợp $x(t) = x_1(t) + x_2(t)$ và dùng công thức tổng thành tích để tìm biên độ, pha ban đầu.

Lời giải Bài 1.13:
• Áp dụng công thức tổng thành tích $\cos u + \cos v = 2\cos\frac{u+v}{2}\cos\frac{u-v}{2}$:
$$x(t) = 2\left[\cos\left(\frac{\pi}{3}t + \frac{\pi}{6}\right) + \cos\left(\frac{\pi}{3}t - \frac{\pi}{3}\right)\right]$$
$$\text{Tổng các góc: } \left(\frac{\pi}{3}t + \frac{\pi}{6}\right) + \left(\frac{\pi}{3}t - \frac{\pi}{3}\right) = \frac{2\pi}{3}t - \frac{\pi}{6} \Rightarrow \text{nửa tổng} = \frac{\pi}{3}t - \frac{\pi}{12}.$$
$$\text{Hiệu các góc: } \left(\frac{\pi}{3}t + \frac{\pi}{6}\right) - \left(\frac{\pi}{3}t - \frac{\pi}{3}\right) = \frac{\pi}{2} \Rightarrow \text{nửa hiệu} = \frac{\pi}{4}.$$
$$x(t) = 2 \cdot 2 \cos\left(\frac{\pi}{3}t - \frac{\pi}{12}\right) \cos\frac{\pi}{4} = 4 \cos\left(\frac{\pi}{3}t - \frac{\pi}{12}\right) \cdot \frac{\sqrt{2}}{2} = 2\sqrt{2}\cos\left(\frac{\pi}{3}t - \frac{\pi}{12}\right).$$
• Biên độ dao động tổng hợp là $A = 2\sqrt{2}\text{ cm}$, pha ban đầu là $\varphi = -\frac{\pi}{12}$.

### b) Hệ thống bài tập cuối bài

**Bài 1.7:** Sử dụng $15^{\circ} = 45^{\circ} - 30^{\circ}$, hãy tính các giá trị lượng giác của góc $15^{\circ}$.

Lời giải Bài 1.7:
• $\sin 15^{\circ} = \sin(45^{\circ} - 30^{\circ}) = \sin 45^{\circ}\cos 30^{\circ} - \cos 45^{\circ}\sin 30^{\circ} = \frac{\sqrt{2}}{2}\frac{\sqrt{3}}{2} - \frac{\sqrt{2}}{2}\frac{1}{2} = \frac{\sqrt{6} - \sqrt{2}}{4}$.
• $\cos 15^{\circ} = \cos(45^{\circ} - 30^{\circ}) = \cos 45^{\circ}\cos 30^{\circ} + \sin 45^{\circ}\sin 30^{\circ} = \frac{\sqrt{6} + \sqrt{2}}{4}$.
• $\tan 15^{\circ} = \frac{\sin 15^{\circ}}{\cos 15^{\circ}} = 2 - \sqrt{3}$. $\cot 15^{\circ} = 2 + \sqrt{3}$.

**Bài 1.8:** Tính:
a) $\cos\left(a + \frac{\pi}{6}\right)$ biết $\sin a = \frac{1}{\sqrt{3}}$ và $\frac{\pi}{2} < a < \pi$;
b) $\tan\left(a - \frac{\pi}{4}\right)$ biết $\cos a = -\frac{1}{3}$ và $\pi < a < \frac{3\pi}{2}$.

Lời giải Bài 1.8:
• a) Vì $\frac{\pi}{2} < a < \pi$ nên $\cos a = -\sqrt{1 - \sin^2 a} = -\sqrt{1 - \frac{1}{3}} = -\sqrt{\frac{2}{3}} = -\frac{\sqrt{6}}{3}$.
  $\cos\left(a + \frac{\pi}{6}\right) = \cos a \cos\frac{\pi}{6} - \sin a \sin\frac{\pi}{6} = \left(-\frac{\sqrt{6}}{3}\right)\frac{\sqrt{3}}{2} - \left(\frac{1}{\sqrt{3}}\right)\frac{1}{2} = -\frac{3\sqrt{2}}{6} - \frac{\sqrt{3}}{6} = -\frac{3\sqrt{2} + \sqrt{3}}{6}$.
• b) Vì $\pi < a < \frac{3\pi}{2}$ nên $\sin a = -\sqrt{1 - \cos^2 a} = -\sqrt{1 - \frac{1}{9}} = -\frac{2\sqrt{2}}{3}$, $\tan a = \frac{\sin a}{\cos a} = 2\sqrt{2}$.
  $\tan\left(a - \frac{\pi}{4}\right) = \frac{\tan a - 1}{1 + \tan a} = \frac{2\sqrt{2} - 1}{2\sqrt{2} + 1} = \frac{(2\sqrt{2} - 1)^2}{8 - 1} = \frac{9 - 4\sqrt{2}}{7}$.

**Bài 1.9:** Tính $\sin 2a, \cos 2a, \tan 2a$ biết:
a) $\sin a = \frac{1}{3}$ và $\frac{\pi}{2} < a < \pi$;
b) $\sin a + \cos a = \frac{1}{2}$ và $\frac{\pi}{2} < a < \frac{3\pi}{4}$.

Lời giải Bài 1.9:
• a) $\cos a = -\sqrt{1 - \frac{1}{9}} = -\frac{2\sqrt{2}}{3}$.
  $\sin 2a = 2\sin a \cos a = 2\left(\frac{1}{3}\right)\left(-\frac{2\sqrt{2}}{3}\right) = -\frac{4\sqrt{2}}{9}$.
  $\cos 2a = 1 - 2\sin^2 a = 1 - 2\left(\frac{1}{9}\right) = \frac{7}{9}$.
  $\tan 2a = \frac{\sin 2a}{\cos 2a} = -\frac{4\sqrt{2}}{7}$.
• b) Từ $\sin a + \cos a = \frac{1}{2} \Rightarrow (\sin a + \cos a)^2 = \frac{1}{4} \Rightarrow 1 + \sin 2a = \frac{1}{4} \Rightarrow \sin 2a = -\frac{3}{4}$.
  Vì $\frac{\pi}{2} < a < \frac{3\pi}{4} \Rightarrow \pi < 2a < \frac{3\pi}{2} \Rightarrow \cos 2a = -\sqrt{1 - \sin^2(2a)} = -\sqrt{1 - \frac{9}{16}} = -\frac{\sqrt{7}}{4}$.
  $\tan 2a = \frac{\sin 2a}{\cos 2a} = \frac{3\sqrt{7}}{7}$.

**Bài 1.10:** Tính giá trị biểu thức:
a) $A = \frac{\sin\frac{\pi}{15}\cos\frac{\pi}{10} + \sin\frac{\pi}{10}\cos\frac{\pi}{15}}{\cos\frac{2\pi}{15}\cos\frac{\pi}{5} - \sin\frac{2\pi}{15}\sin\frac{\pi}{5}}$;
b) $B = \sin\frac{\pi}{32}\cos\frac{\pi}{32}\cos\frac{\pi}{16}\cos\frac{\pi}{8}$.

Lời giải Bài 1.10:
• a) $A = \frac{\sin\left(\frac{\pi}{15} + \frac{\pi}{10}\right)}{\cos\left(\frac{2\pi}{15} + \frac{\pi}{5}\right)} = \frac{\sin\frac{5\pi}{30}}{\cos\frac{5\pi}{15}} = \frac{\sin\frac{\pi}{6}}{\cos\frac{\pi}{3}} = \frac{1/2}{1/2} = 1$.
• b) Sử dụng công thức nhân đôi liên tiếp $2\sin x \cos x = \sin 2x$:
  $B = \frac{1}{2} \cdot \left(2\sin\frac{\pi}{32}\cos\frac{\pi}{32}\right)\cos\frac{\pi}{16}\cos\frac{\pi}{8} = \frac{1}{2}\sin\frac{\pi}{16}\cos\frac{\pi}{16}\cos\frac{\pi}{8} = \frac{1}{4}\sin\frac{\pi}{8}\cos\frac{\pi}{8} = \frac{1}{8}\sin\frac{\pi}{4} = \frac{1}{8} \cdot \frac{\sqrt{2}}{2} = \frac{\sqrt{2}}{16}$.
