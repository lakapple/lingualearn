## Concept of the Second Derivative

<Youtube url="https://www.youtube.com/watch?v=example_dao_ham_cap_hai"/>

### a) Definition of the Second Derivative

Suppose the function $y = f(x)$ has a derivative at each point $x \in (a; b)$. If the derivative function $y' = f'(x)$ is itself differentiable at $x$, then the derivative of $y'$ is called the second derivative of the function $y = f(x)$ at $x$, denoted by $y''$ or $f''(x)$, that is:
$$f''(x) = (f'(x))'$$
The $n$-th order derivative ($n \ge 3$) of the function $y = f(x)$ is defined inductively as the derivative of the $(n - 1)$-th order derivative:
$$f^{(n)}(x) = (f^{(n-1)}(x))'$$

### b) Examples and Practice on Computing Second Derivatives

**Example 1:** Compute the second derivative of the function $y = x^2 + e^{2x - 1}$. From this result, evaluate $y''(0)$.

Solution to Example 1:
• The first derivative of the function is:
  $$y' = 2x + (2x - 1)' \cdot e^{2x - 1} = 2x + 2e^{2x - 1}.$$
• The second derivative of the function is:
  $$y'' = (y')' = 2 + 2(2x - 1)' \cdot e^{2x - 1} = 2 + 4e^{2x - 1}.$$
• At $x = 0$, we have:
  $$y''(0) = 2 + 4e^{2(0) - 1} = 2 + 4e^{-1} = 2 + \frac{4}{e}.$$

**Practice 1:** Compute the second derivative of the following functions:
a) $y = x e^{2x}$;
b) $y = \ln(2x + 3)$.

Solution to Practice 1:
• a) First derivative of $y = x e^{2x}$:
  $$y' = (x)' e^{2x} + x (e^{2x})' = e^{2x} + 2x e^{2x} = (2x + 1) e^{2x}.$$
  Second derivative:
  $$y'' = (2x + 1)' e^{2x} + (2x + 1) (e^{2x})' = 2e^{2x} + 2(2x + 1) e^{2x} = (4x + 4) e^{2x} = 4(x + 1) e^{2x}.$$
• b) Domain condition $2x + 3 > 0 \iff x > -\frac{3}{2}$.
  First derivative of $y = \ln(2x + 3)$:
  $$y' = \frac{(2x + 3)'}{2x + 3} = \frac{2}{2x + 3} = 2(2x + 3)^{-1}.$$
  Second derivative:
  $$y'' = \left(\frac{2}{2x + 3}\right)' = 2 \cdot \frac{-(2x + 3)'}{(2x + 3)^2} = -\frac{4}{(2x + 3)^2}.$$

## Mechanical Meaning of the Second Derivative

### a) Instantaneous Acceleration of Motion

Consider rectilinear motion described by the position function $s = f(t)$:
• The instantaneous velocity at time $t$ is the first derivative of position with respect to time: $v(t) = s'(t) = f'(t)$.
• Given a time increment $\Delta t$ at instant $t$, the ratio $\frac{\Delta v}{\Delta t} = \frac{v(t + \Delta t) - v(t)}{\Delta t}$ is called the average acceleration over the time interval $\Delta t$.
• The limit of the average acceleration as $\Delta t \to 0$ is the instantaneous acceleration $a(t)$ of the motion at time $t$:
$$a(t) = \lim\_{\Delta t \to 0} \frac{\Delta v}{\Delta t} = v'(t)$$
Theorem (Mechanical Meaning of the Second Derivative): In motion governed by the position equation $s = f(t)$, the second derivative of the function $f(t)$ represents the instantaneous acceleration of the motion at time $t$:
$$a(t) = s''(t) = f''(t)$$

### b) Examples and Problems on Spring Pendulum Oscillation

**Example 2:** The motion of an object attached to a spring pendulum (neglecting friction and air resistance) is described by the displacement equation:
$$x(t) = 4 \cos\left(2\pi t + \frac{\pi}{3}\right)$$
where $x$ is measured in centimeters and time $t$ in seconds. Find the instantaneous acceleration of the object at time $t = 5$ seconds (round the result to the nearest integer).

Solution to Example 2:
• The instantaneous velocity of the object at time $t$ is the first derivative of displacement:
  $$v(t) = x'(t) = -4 \cdot \left(2\pi t + \frac{\pi}{3}\right)' \sin\left(2\pi t + \frac{\pi}{3}\right) = -8\pi \sin\left(2\pi t + \frac{\pi}{3}\right)\text{ (cm/s).}$$
• The instantaneous acceleration of the object at time $t$ is the second derivative of displacement (the derivative of velocity):
  $$a(t) = v'(t) = x''(t) = -8\pi \cdot \left(2\pi t + \frac{\pi}{3}\right)' \cos\left(2\pi t + \frac{\pi}{3}\right) = -16\pi^2 \cos\left(2\pi t + \frac{\pi}{3}\right)\text{ (cm/s}^2\text{).}$$
• At time $t = 5$ seconds:
  $$a(5) = -16\pi^2 \cos\left(10\pi + \frac{\pi}{3}\right) = -16\pi^2 \cos\frac{\pi}{3} = -16\pi^2 \cdot \frac{1}{2} = -8\pi^2 \approx -8 \cdot (3.14159)^2 \approx -79\text{ (cm/s}^2\text{).}$$

**Application:** An object moves along a straight line according to the equation $s(t) = 2t^2 + \frac{1}{2}t^4$ ($s$ in meters, $t$ in seconds). Find the acceleration of the object at time $t = 4$ seconds.

Solution to Application:
• The instantaneous velocity of the object is:
  $$v(t) = s'(t) = 4t + 2t^3\text{ (m/s).}$$
• The instantaneous acceleration of the object is:
  $$a(t) = s''(t) = v'(t) = 4 + 6t^2\text{ (m/s}^2\text{).}$$
• At time $t = 4$ seconds, the acceleration of the object is:
  $$a(4) = 4 + 6(4^2) = 4 + 6(16) = 4 + 96 = 100\text{ (m/s}^2\text{).}$$

## Applications and Exercises

### a) Exercises on Computing the Second Derivative of Functions

**Exercise 9.13:** Given the function $f(x) = x^2 e^x$. Compute $f''(0)$.

Solution to Exercise 9.13:
• Applying the product rule for the first derivative:
  $$f'(x) = (x^2)' e^x + x^2 (e^x)' = 2x e^x + x^2 e^x = (x^2 + 2x) e^x.$$
• Computing the second derivative:
  $$f''(x) = (x^2 + 2x)' e^x + (x^2 + 2x) (e^x)' = (2x + 2) e^x + (x^2 + 2x) e^x = (x^2 + 4x + 2) e^x.$$
• At $x = 0$, we have:
  $$f''(0) = (0^2 + 4 \cdot 0 + 2) e^0 = 2 \cdot 1 = 2.$$

**Exercise 9.14:** Compute the second derivative of the following functions:
a) $y = \ln(x + 1)$ (for $x > -1$);
b) $y = \tan 2x$ (for $x \ne \frac{\pi}{4} + k\frac{\pi}{2}, k \in \mathbb{Z}$).

Solution to Exercise 9.14:
• a) First derivative: $y' = \frac{(x+1)'}{x+1} = \frac{1}{x+1} = (x+1)^{-1}$.
  Second derivative: $y'' = \left(\frac{1}{x+1}\right)' = -\frac{(x+1)'}{(x+1)^2} = -\frac{1}{(x+1)^2}$.
• b) First derivative: $y' = (\tan 2x)' = \frac{(2x)'}{\cos^2 2x} = \frac{2}{\cos^2 2x} = 2(1 + \tan^2 2x)$.
  Second derivative:
  $$y'' = [2(1 + \tan^2 2x)]' = 2 \cdot 2\tan 2x \cdot (\tan 2x)' = 4\tan 2x \cdot \frac{2}{\cos^2 2x} = \frac{8\tan 2x}{\cos^2 2x} = \frac{8\sin 2x}{\cos^3 2x}.$$

**Exercise 9.15:** Given the polynomial $P(x) = ax^2 + bx + 3$ ($a, b$ are constants). Find $a$ and $b$ given that $P'(1) = 0$ and $P''(1) = -2$.

Solution to Exercise 9.15:
• Finding the first and second derivatives of the polynomial:
  $$P'(x) = 2ax + b$$
  $$P''(x) = 2a$$
• From the condition $P''(1) = -2 \implies 2a = -2 \iff a = -1$.
• Substituting $a = -1$ into the equation $P'(1) = 0$:
  $$P'(1) = 2(-1)(1) + b = -2 + b = 0 \iff b = 2.$$
• Thus, the required values are $a = -1$ and $b = 2$.

**Exercise 9.16:** Given the function $f(x) = 2\sin^2\left(x + \frac{\pi}{4}\right)$. Prove that $|f''(x)| \le 4$ for all $x \in \mathbb{R}$.

Solution to Exercise 9.16:
• Using the power-reduction formula:
  $$f(x) = 1 - \cos\left(2x + \frac{\pi}{2}\right) = 1 - (-\sin 2x) = 1 + \sin 2x.$$
• Computing the first derivative:
  $$f'(x) = (1 + \sin 2x)' = 2\cos 2x.$$
• Computing the second derivative:
  $$f''(x) = (2\cos 2x)' = 2(-2\sin 2x) = -4\sin 2x.$$
• Since $|\sin 2x| \le 1$ for all $x \in \mathbb{R}$, we have:
  $$|f''(x)| = |-4\sin 2x| = 4|\sin 2x| \le 4.$$
• The inequality is proved.

### b) Physical Applications of Acceleration

**Exercise 9.17:** The motion of a particle is given by $s(t) = 10 + 0.5\sin\left(2\pi t + \frac{\pi}{5}\right)$, where $s$ is in centimeters and $t$ in seconds. Find the acceleration of the particle at time $t = 5$ seconds (round the result to one decimal place).

Solution to Exercise 9.17:
• The instantaneous velocity of the particle is:
  $$v(t) = s'(t) = 0.5 \cdot 2\pi \cos\left(2\pi t + \frac{\pi}{5}\right) = \pi \cos\left(2\pi t + \frac{\pi}{5}\right)\text{ (cm/s).}$$
• The instantaneous acceleration of the particle is:
  $$a(t) = s''(t) = v'(t) = -\pi \cdot 2\pi \sin\left(2\pi t + \frac{\pi}{5}\right) = -2\pi^2 \sin\left(2\pi t + \frac{\pi}{5}\right)\text{ (cm/s}^2\text{).}$$
• At time $t = 5$ seconds:
  $$a(5) = -2\pi^2 \sin\left(10\pi + \frac{\pi}{5}\right) = -2\pi^2 \sin\frac{\pi}{5} = -2\pi^2 \sin 36^{\circ}.$$
• Evaluating with $\pi \approx 3.14159$ and $\sin 36^{\circ} \approx 0.5878$:
  $$a(5) \approx -2 \cdot (9.8696) \cdot 0.5878 \approx -11.6\text{ (cm/s}^2\text{).}$$
