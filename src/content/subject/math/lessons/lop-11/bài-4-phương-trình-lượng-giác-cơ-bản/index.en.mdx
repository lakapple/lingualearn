## Concept of Equivalent Equations

<Youtube url="https://www.youtube.com/watch?v=example_phuong_trinh_tuong_duong"/>

### a) Definition of Equivalent Equations

Definition:
Two equations are called equivalent if they share the exact same solution set.
If the equation $f(x) = 0$ is equivalent to $g(x) = 0$, we write $f(x) = 0 \Leftrightarrow g(x) = 0$.
Remark: Two equations that both have no real solutions (empty solution set) are equivalent.

### b) Equivalent Algebraic Transformations

Standard Equivalent Transformations:
• Adding or subtracting the same number or expression on both sides without altering the domain of definition:
$$f(x) = g(x) \Leftrightarrow f(x) + h(x) = g(x) + h(x)$$
• Multiplying or dividing both sides by a non-zero constant or an expression that never vanishes ($h(x) \ne 0$):
$$f(x) = g(x) \Leftrightarrow f(x)h(x) = g(x)h(x) \quad (h(x) \ne 0)$$

**Example 1:** Are the two equations $2x + 6 = 0$ and $x^2 + 6x + 9 = 0$ equivalent?

Solution for Example 1:
• $2x + 6 = 0 \Leftrightarrow x = -3$, so the solution set is $S_1 = \\{-3\\}$.
• $x^2 + 6x + 9 = 0 \Leftrightarrow (x + 3)^2 = 0 \Leftrightarrow x = -3$, so the solution set is $S_2 = \\{-3\\}$.
• Since $S_1 = S_2 = \\{-3\\}$, the two equations are equivalent.

**Practice 1:** Determine whether the following two equations are equivalent: $\frac{x - 1}{x + 1} = 0$ and $x^2 - 1 = 0$.

Solution for Practice 1:
• The equation $\frac{x - 1}{x + 1} = 0$ has domain $x \ne -1$, which yields $x = 1$, so $S_1 = \\{1\\}$.
• The equation $x^2 - 1 = 0 \Leftrightarrow x = \pm 1$, so $S_2 = \\{-1; 1\\}$.
• Since $S_1 \ne S_2$, the two equations are not equivalent.

## Equations sin x = m and cos x = m

<Youtube url="https://www.youtube.com/watch?v=example_phuong_trinh_sin_cos"/>

### a) Solution Formulas for sin x = m

Solvability Conditions and General Formulas:
• If $|m| > 1$, the equation $\sin x = m$ has no real solution.
• If $|m| \le 1$, there exists a unique angle $\alpha \in \left[-\frac{\pi}{2}; \frac{\pi}{2}\right]$ such that $\sin\alpha = m$. Then:
$$\sin x = m \Leftrightarrow \sin x = \sin\alpha \Leftrightarrow \begin{cases} x = \alpha + k2\pi \\\ x = \pi - \alpha + k2\pi \end{cases} (k \in \mathbb{Z})$$
• In degree measure:
$$\sin x = \sin\alpha^{\circ} \Leftrightarrow \begin{cases} x = \alpha^{\circ} + k360^{\circ} \\\ x = 180^{\circ} - \alpha^{\circ} + k360^{\circ} \end{cases} (k \in \mathbb{Z})$$
• Special cases:
  + $\sin x = 0 \Leftrightarrow x = k\pi \quad (k \in \mathbb{Z})$;
  + $\sin x = 1 \Leftrightarrow x = \frac{\pi}{2} + k2\pi \quad (k \in \mathbb{Z})$;
  + $\sin x = -1 \Leftrightarrow x = -\frac{\pi}{2} + k2\pi \quad (k \in \mathbb{Z})$.

**Example 2:** Solve the following equations:
a) $\sin x = -\frac{\sqrt{3}}{2}$;
b) $\sin 2x = \sin(60^{\circ} - 3x)$.

Solution for Example 2:
• a) $\sin x = -\frac{\sqrt{3}}{2} \Leftrightarrow \sin x = \sin\left(-\frac{\pi}{3}\right) \Leftrightarrow \begin{cases} x = -\frac{\pi}{3} + k2\pi \\\ x = \frac{4\pi}{3} + k2\pi \end{cases} (k \in \mathbb{Z})$.
• b) $\sin 2x = \sin(60^{\circ} - 3x) \Leftrightarrow \begin{cases} 2x = 60^{\circ} - 3x + k360^{\circ} \\\ 2x = 180^{\circ} - (60^{\circ} - 3x) + k360^{\circ} \end{cases} \Leftrightarrow \begin{cases} x = 12^{\circ} + k72^{\circ} \\\ x = -120^{\circ} - k360^{\circ} \end{cases} (k \in \mathbb{Z})$.

### b) Solution Formulas for cos x = m

Solvability Conditions and General Formulas:
• If $|m| > 1$, the equation $\cos x = m$ has no real solution.
• If $|m| \le 1$, there exists a unique angle $\alpha \in [0; \pi]$ such that $\cos\alpha = m$. Then:
$$\cos x = m \Leftrightarrow \cos x = \cos\alpha \Leftrightarrow x = \pm \alpha + k2\pi \quad (k \in \mathbb{Z})$$
• In degree measure:
$$\cos x = \cos\alpha^{\circ} \Leftrightarrow x = \pm \alpha^{\circ} + k360^{\circ} \quad (k \in \mathbb{Z})$$
• Special cases:
  + $\cos x = 0 \Leftrightarrow x = \frac{\pi}{2} + k\pi \quad (k \in \mathbb{Z})$;
  + $\cos x = 1 \Leftrightarrow x = k2\pi \quad (k \in \mathbb{Z})$;
  + $\cos x = -1 \Leftrightarrow x = \pi + k2\pi \quad (k \in \mathbb{Z})$.

**Examples 5 & 6:** Solve the following equations:
a) $\cos x = -\frac{\sqrt{3}}{2}$;
b) $\cos 2x = \cos(45^{\circ} - x)$.

Solution for Examples 5 & 6:
• a) $\cos x = -\frac{\sqrt{3}}{2} \Leftrightarrow \cos x = \cos\frac{5\pi}{6} \Leftrightarrow x = \pm \frac{5\pi}{6} + k2\pi \quad (k \in \mathbb{Z})$.
• b) $\cos 2x = \cos(45^{\circ} - x) \Leftrightarrow \begin{cases} 2x = 45^{\circ} - x + k360^{\circ} \\\ 2x = -(45^{\circ} - x) + k360^{\circ} \end{cases} \Leftrightarrow \begin{cases} x = 15^{\circ} + k120^{\circ} \\\ x = -45^{\circ} + k360^{\circ} \end{cases} (k \in \mathbb{Z})$.

**Practice 3:** Solve the following equations:
a) $2\cos x = -\sqrt{2}$;
b) $\cos 3x - \sin 5x = 0$.

Solution for Practice 3:
• a) $2\cos x = -\sqrt{2} \Leftrightarrow \cos x = -\frac{\sqrt{2}}{2} = \cos\frac{3\pi}{4} \Leftrightarrow x = \pm \frac{3\pi}{4} + k2\pi \quad (k \in \mathbb{Z})$.
• b) $\cos 3x - \sin 5x = 0 \Leftrightarrow \cos 3x = \sin 5x = \cos\left(\frac{\pi}{2} - 5x\right)$
  $$\Leftrightarrow \begin{cases} 3x = \frac{\pi}{2} - 5x + k2\pi \\\ 3x = -\left(\frac{\pi}{2} - 5x\right) + k2\pi \end{cases} \Leftrightarrow \begin{cases} 8x = \frac{\pi}{2} + k2\pi \\\ -2x = -\frac{\pi}{2} + k2\pi \end{cases} \Leftrightarrow \begin{cases} x = \frac{\pi}{16} + \frac{k\pi}{4} \\\ x = \frac{\pi}{4} - k\pi \end{cases} (k \in \mathbb{Z}).$$

## Equations tan x = m and cot x = m

<Youtube url="https://www.youtube.com/watch?v=example_phuong_trinh_tan_cot"/>

### a) Solution Formulas for tan x = m

Solution Formulas:
• The equation $\tan x = m$ has real solutions for all $m \in \mathbb{R}$.
• For every $m \in \mathbb{R}$, there exists a unique $\alpha \in \left(-\frac{\pi}{2}; \frac{\pi}{2}\right)$ such that $\tan\alpha = m$. Then:
$$\tan x = m \Leftrightarrow \tan x = \tan\alpha \Leftrightarrow x = \alpha + k\pi \quad (k \in \mathbb{Z})$$
• In degree measure: $\tan x = \tan\alpha^{\circ} \Leftrightarrow x = \alpha^{\circ} + k180^{\circ} \quad (k \in \mathbb{Z})$.

### b) Solution Formulas for cot x = m

Solution Formulas:
• The equation $\cot x = m$ has real solutions for all $m \in \mathbb{R}$.
• For every $m \in \mathbb{R}$, there exists a unique $\alpha \in (0; \pi)$ such that $\cot\alpha = m$. Then:
$$\cot x = m \Leftrightarrow \cot x = \cot\alpha \Leftrightarrow x = \alpha + k\pi \quad (k \in \mathbb{Z})$$
• In degree measure: $\cot x = \cot\alpha^{\circ} \Leftrightarrow x = \alpha^{\circ} + k180^{\circ} \quad (k \in \mathbb{Z})$.

**Examples 7 & 8:** Solve the following equations:
a) $\tan x = -\sqrt{3}$;
b) $\cot x = -\sqrt{3}$.

Solution for Examples 7 & 8:
• a) $\tan x = -\sqrt{3} \Leftrightarrow \tan x = \tan\left(-\frac{\pi}{3}\right) \Leftrightarrow x = -\frac{\pi}{3} + k\pi \quad (k \in \mathbb{Z})$.
• b) $\cot x = -\sqrt{3} \Leftrightarrow \cot x = \cot\left(\frac{5\pi}{6}\right) \Leftrightarrow x = \frac{5\pi}{6} + k\pi \quad (k \in \mathbb{Z})$.

**Practices 4 & 5:** Solve the following equations:
a) $\sqrt{3}\tan 2x = -1$;
b) $\sqrt{3}\cot x + 1 = 0$.

Solution for Practices 4 & 5:
• a) $\sqrt{3}\tan 2x = -1 \Leftrightarrow \tan 2x = -\frac{1}{\sqrt{3}} = \tan\left(-\frac{\pi}{6}\right) \Leftrightarrow 2x = -\frac{\pi}{6} + k\pi \Leftrightarrow x = -\frac{\pi}{12} + \frac{k\pi}{2} \quad (k \in \mathbb{Z})$.
• b) $\sqrt{3}\cot x + 1 = 0 \Leftrightarrow \cot x = -\frac{1}{\sqrt{3}} = \cot\left(\frac{2\pi}{3}\right) \Leftrightarrow x = \frac{2\pi}{3} + k\pi \quad (k \in \mathbb{Z})$.

## Applications and Exercises

### a) Real-World Applications and Modeling

**Application 1 (Optimal Artillery Firing Angle):** A projectile is fired from ground level with fixed initial velocity $v_0$ at an angle of elevation $\alpha$ ($0^{\circ} \le \alpha \le 90^{\circ}$). The horizontal range reached by the projectile is modeled by $x = \frac{v_0^2 \sin 2\alpha}{g}$. Find the firing angle $\alpha$ that maximizes the projectile range.

Solution for Application 1:
• The horizontal range is $x = \frac{v_0^2\sin 2\alpha}{g} \le \frac{v_0^2}{g}$ (since $\sin 2\alpha \le 1$).
• The maximum range is attained when $\sin 2\alpha = 1 \Leftrightarrow 2\alpha = 90^{\circ} + k360^{\circ} \Leftrightarrow \alpha = 45^{\circ} + k180^{\circ}$.
• Since $0^{\circ} \le \alpha \le 90^{\circ}$, we select $\alpha = 45^{\circ}$.
• Conclusion: The firing angle that achieves maximum distance is $\alpha = 45^{\circ}$.

**Application 2 (Lunar Phases and Illumination Fraction):** The fraction of the Moon illuminated by the Sun as observed from Earth is modeled by $F = \frac{1}{2}(1 - \cos\alpha)$ ($0^{\circ} \le \alpha \le 360^{\circ}$). Find the angle $\alpha$ corresponding to:
a) $F = 0$ (New Moon);
b) $F = 0.25$ (Crescent Moon);
c) $F = 0.5$ (First/Last Quarter Moon);
d) $F = 1$ (Full Moon).

Solution for Application 2:
• a) $F = 0 \Leftrightarrow \frac{1}{2}(1 - \cos\alpha) = 0 \Leftrightarrow \cos\alpha = 1 \Rightarrow \alpha = 0^{\circ}$ or $\alpha = 360^{\circ}$.
• b) $F = 0.25 \Leftrightarrow \frac{1}{2}(1 - \cos\alpha) = 0.25 \Leftrightarrow \cos\alpha = 0.5 \Rightarrow \alpha = 60^{\circ}$ or $\alpha = 300^{\circ}$.
• c) $F = 0.5 \Leftrightarrow \frac{1}{2}(1 - \cos\alpha) = 0.5 \Leftrightarrow \cos\alpha = 0 \Rightarrow \alpha = 90^{\circ}$ or $\alpha = 270^{\circ}$.
• d) $F = 1 \Leftrightarrow \frac{1}{2}(1 - \cos\alpha) = 1 \Leftrightarrow \cos\alpha = -1 \Rightarrow \alpha = 180^{\circ}$.

**Exercise 1.22 (Equilibrium Crossings in Simple Harmonic Motion):** An object oscillates harmonically about its equilibrium position according to $x = 2\cos\left(5t - \frac{\pi}{6}\right)$ ($t$ in seconds, $x$ in cm). How many times does the object pass through the equilibrium position during the time interval from $0$ to $6$ seconds?

Solution for Exercise 1.22:
• The object passes through equilibrium when $x = 0 \Leftrightarrow 2\cos\left(5t - \frac{\pi}{6}\right) = 0$
  $$\Leftrightarrow 5t - \frac{\pi}{6} = \frac{\pi}{2} + k\pi \Leftrightarrow 5t = \frac{2\pi}{3} + k\pi \Leftrightarrow t = \frac{2\pi}{15} + \frac{k\pi}{5} \quad (k \in \mathbb{Z}).$$
• For $0 \le t \le 6$:
  $$0 \le \frac{2\pi}{15} + \frac{k\pi}{5} \le 6 \Leftrightarrow -\frac{2\pi}{15} \le \frac{k\pi}{5} \le 6 - \frac{2\pi}{15}$$
  $$\Leftrightarrow -\frac{2}{3} \le k \le \frac{30}{\pi} - \frac{2}{3} \approx 9.55 - 0.67 = 8.88.$$
• Since $k \in \mathbb{Z}$, the permissible integer values are $k \in \\{0; 1; 2; 3; 4; 5; 6; 7; 8\\}$ (total of 9 values).
• Conclusion: During the interval from 0 to 6 seconds, the object passes through the equilibrium position 9 times.

### b) Detailed Section Exercises

**Exercise 1.19:** Solve the following equations:
a) $\sin x = \frac{\sqrt{3}}{2}$;
b) $2\cos x = -\sqrt{2}$;
c) $\sqrt{3}\tan\left(\frac{x}{2} + 15^{\circ}\right) = 1$;
d) $\cot(2x - 1) = \cot\frac{\pi}{5}$.

Solution for Exercise 1.19:
• a) $\sin x = \frac{\sqrt{3}}{2} = \sin\frac{\pi}{3} \Leftrightarrow \begin{cases} x = \frac{\pi}{3} + k2\pi \\\ x = \frac{2\pi}{3} + k2\pi \end{cases} (k \in \mathbb{Z})$.
• b) $\cos x = -\frac{\sqrt{2}}{2} = \cos\frac{3\pi}{4} \Leftrightarrow x = \pm \frac{3\pi}{4} + k2\pi \quad (k \in \mathbb{Z})$.
• c) $\tan\left(\frac{x}{2} + 15^{\circ}\right) = \frac{1}{\sqrt{3}} = \tan 30^{\circ} \Leftrightarrow \frac{x}{2} + 15^{\circ} = 30^{\circ} + k180^{\circ} \Leftrightarrow \frac{x}{2} = 15^{\circ} + k180^{\circ} \Leftrightarrow x = 30^{\circ} + k360^{\circ} \quad (k \in \mathbb{Z})$.
• d) Domain: $\sin(2x - 1) \ne 0$. $\cot(2x - 1) = \cot\frac{\pi}{5} \Leftrightarrow 2x - 1 = \frac{\pi}{5} + k\pi \Leftrightarrow 2x = 1 + \frac{\pi}{5} + k\pi \Leftrightarrow x = \frac{1}{2} + \frac{\pi}{10} + \frac{k\pi}{2} \quad (k \in \mathbb{Z})$.

**Exercise 1.20:** Solve the following equations:
a) $\sin 2x + \cos 4x = 0$;
b) $\cos 3x = -\cos 7x$.

Solution for Exercise 1.20:
• a) $\sin 2x = -\cos 4x = \cos(4x + \pi) = \sin\left(\frac{\pi}{2} - (4x + \pi)\right) = \sin\left(-4x - \frac{\pi}{2}\right)$
  $$\Leftrightarrow \begin{cases} 2x = -4x - \frac{\pi}{2} + k2\pi \\\ 2x = \pi - \left(-4x - \frac{\pi}{2}\right) + k2\pi \end{cases} \Leftrightarrow \begin{cases} 6x = -\frac{\pi}{2} + k2\pi \\\ -2x = \frac{3\pi}{2} + k2\pi \end{cases} \Leftrightarrow \begin{cases} x = -\frac{\pi}{12} + \frac{k\pi}{3} \\\ x = -\frac{3\pi}{4} - k\pi \end{cases} (k \in \mathbb{Z}).$$
• b) $\cos 3x = -\cos 7x = \cos(\pi - 7x) \Leftrightarrow \begin{cases} 3x = \pi - 7x + k2\pi \\\ 3x = -(\pi - 7x) + k2\pi \end{cases} \Leftrightarrow \begin{cases} 10x = \pi + k2\pi \\\ -4x = -\pi + k2\pi \end{cases} \Leftrightarrow \begin{cases} x = \frac{\pi}{10} + \frac{k\pi}{5} \\\ x = \frac{\pi}{4} - \frac{k\pi}{2} \end{cases} (k \in \mathbb{Z})$.

**Exercise 1.21:** A projectile is fired from the ground with $v_0 = 500\text{ m/s}$ at an angle of elevation $\alpha$, following trajectory: $y = \frac{-g}{2v_0^2\cos^2\alpha}x^2 + x\tan\alpha$ with $g = 9.8\text{ m/s}^2$.
a) Formulate the projectile range in terms of $\alpha$.
b) Find the angle $\alpha$ required to hit a target located $22\\,000\text{ m}$ away.

Solution for Exercise 1.21:
• a) The projectile lands when $y = 0 \Leftrightarrow x\left(\tan\alpha - \frac{g x}{2v_0^2\cos^2\alpha}\right) = 0$.
  For $x > 0$, the range is: $x = \frac{2v_0^2\tan\alpha\cos^2\alpha}{g} = \frac{2v_0^2\sin\alpha\cos\alpha}{g} = \frac{v_0^2\sin 2\alpha}{g}$.
• b) To reach a target $22\\,000\text{ m}$ away:
  $$\frac{500^2\sin 2\alpha}{9.8} = 22\\,000 \Leftrightarrow 250\\,000\sin 2\alpha = 215\\,600 \Leftrightarrow \sin 2\alpha = \frac{215\\,600}{250\\,000} = 0.8624.$$
  Using a handheld calculator: $2\alpha \approx 59^{\circ}35' \Rightarrow \alpha_1 \approx 29^{\circ}47'$.
  Or $2\alpha = 180^{\circ} - 59^{\circ}35' = 120^{\circ}25' \Rightarrow \alpha_2 \approx 60^{\circ}13'$.
  Thus, there are two valid firing angles: $\alpha \approx 29^{\circ}47'$ and $\alpha \approx 60^{\circ}13'$.
