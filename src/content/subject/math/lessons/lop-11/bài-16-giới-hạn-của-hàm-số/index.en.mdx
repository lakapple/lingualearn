## Lesson Objectives

### **Terminology:**

·       Limit of a function (finite limit at a point)

·       One-sided limits (left-hand limit, right-hand limit)

·       Limits at infinity (x tending to +∞, x tending to -∞)

·       Infinite limits (+∞, -∞)

### **Knowledge and Skills:**

·       Recognize the concept of finite limits of a function at a point and at infinity.

·       Understand and proficiently apply the concept of one-sided limits.

·       Recognize and apply rules for calculating infinite limits.

·       Proficiently evaluate various types of limits of functions (indeterminate form 0/0, dividing by the highest power of x, multiplying by conjugate expressions).

·       Apply limits of functions to solve practical problems (Einstein's Special Relativity, geometric motion).

## Finite Limits of a Function at a Point

<Youtube url="https://www.youtube.com/watch?v=example_gioi_han_ham_so_tai_mot_diem"/>

### a) Definition of Limit at a Point

Definition: Let $(a; b)$ be an open interval containing $x_0$ and let $y = f(x)$ be a function defined on $(a; b)$, possibly except at $x_0$. We say that the function $f(x)$ has the limit $L$ as $x$ approaches $x_0$ if for every sequence $(x_n)$ such that $x_n \in (a; b) \setminus \\{x_0\\}$ and $x_n \to x_0$, we have $f(x_n) \to L$, denoted by:
$$\lim\_{x \to x_0} f(x) = L \quad \text{or} \quad f(x) \to L \text{ as } x \to x_0.$$
Rules for Evaluating Finite Limits at a Point:
If $\lim\_{x \to x_0} f(x) = L$ and $\lim\_{x \to x_0} g(x) = M$, then:
• $\lim\_{x \to x_0} [f(x) \pm g(x)] = L \pm M$;
• $\lim\_{x \to x_0} [f(x) \cdot g(x)] = L \cdot M$;
• $\lim\_{x \to x_0} \frac{f(x)}{g(x)} = \frac{L}{M}$ (if $M \ne 0$);
• If $f(x) \ge 0$ for all $x \in (a; b) \setminus \\{x_0\\}$, then $L \ge 0$ and $\lim\_{x \to x_0} \sqrt{f(x)} = \sqrt{L}$.
Note: For any constant $c$, $\lim\_{x \to x_0} c = c$; for any $n \in \mathbb{N}^*$, $\lim\_{x \to x_0} x^n = x_0^n$.

### b) Examples and Practice on Limits at a Point

**Example 1:** Given the function $f(x) = \frac{x - 1}{x^2 - 1}$. Prove that $\lim\_{x \to 1} f(x) = \frac{1}{2}$.

Solution to Example 1:
• Consider an arbitrary sequence $(x_n)$ such that $x_n \ne 1$ and $x_n \to 1$. We have:
  $$f(x_n) = \frac{x_n - 1}{x_n^2 - 1} = \frac{1}{x_n + 1}$$
• Therefore: $\lim\_{n \to +\infty} f(x_n) = \lim\_{n \to +\infty} \frac{1}{x_n + 1} = \frac{1}{1 + 1} = \frac{1}{2}$.
• Thus, $\lim\_{x \to 1} f(x) = \frac{1}{2}$.

**Example 2:** Let $f(x) = x - 1$ and $g(x) = x^3$. Compute the following limits:
a) $\lim\_{x \to 1} [3f(x) - g(x)]$;
b) $\lim\_{x \to 1} \frac{[f(x)]^2}{g(x)}$.

Solution to Example 2:
• We have $\lim\_{x \to 1} f(x) = \lim\_{x \to 1} (x - 1) = 0$ and $\lim\_{x \to 1} g(x) = \lim\_{x \to 1} x^3 = 1$.
• a) $\lim\_{x \to 1} [3f(x) - g(x)] = 3\lim\_{x \to 1} f(x) - \lim\_{x \to 1} g(x) = 3 \cdot 0 - 1 = -1$.
• b) $\lim\_{x \to 1} \frac{[f(x)]^2}{g(x)} = \frac{[\lim\_{x \to 1} f(x)]^2}{\lim\_{x \to 1} g(x)} = \frac{0^2}{1} = 0$.

**Example 3:** Evaluate $\lim\_{x \to 0} \frac{\sqrt{x + 9} - 3}{x}$.

Solution to Example 3:
• As $x \to 0$, both the numerator and the denominator approach 0 (indeterminate form $\frac{0}{0}$). Multiplying both numerator and denominator by the conjugate expression $(\sqrt{x + 9} + 3)$:
  $$\frac{\sqrt{x + 9} - 3}{x} = \frac{(\sqrt{x + 9})^2 - 3^2}{x(\sqrt{x + 9} + 3)} = \frac{x}{x(\sqrt{x + 9} + 3)} = \frac{1}{\sqrt{x + 9} + 3}$$
• Thus: $\lim\_{x \to 0} \frac{\sqrt{x + 9} - 3}{x} = \lim\_{x \to 0} \frac{1}{\sqrt{x + 9} + 3} = \frac{1}{\sqrt{0 + 9} + 3} = \frac{1}{6}$.

**Practice 1:** Evaluate $\lim\_{x \to 1} \frac{x - 1}{\sqrt{x} - 1}$.

Solution to Practice 1:
• Multiplying by the conjugate or factoring the numerator: $x - 1 = (\sqrt{x} - 1)(\sqrt{x} + 1)$ for $x \ge 0, x \ne 1$:
  $$\lim\_{x \to 1} \frac{x - 1}{\sqrt{x} - 1} = \lim\_{x \to 1} (\sqrt{x} + 1) = \sqrt{1} + 1 = 2.$$

### c) One-Sided Limits

• Right-hand limit: Let function $y = f(x)$ be defined on $(x_0; b)$. We say that $L$ is the right-hand limit of $f(x)$ as $x \to x_0$ if for every sequence $(x_n)$ such that $x_0 < x_n < b$ and $x_n \to x_0$, we have $f(x_n) \to L$, denoted by $\lim\_{x \to x_0^+} f(x) = L$.
• Left-hand limit: Let function $y = f(x)$ be defined on $(a; x_0)$. We say that $L$ is the left-hand limit of $f(x)$ as $x \to x_0$ if for every sequence $(x_n)$ such that $a < x_n < x_0$ and $x_n \to x_0$, we have $f(x_n) \to L$, denoted by $\lim\_{x \to x_0^-} f(x) = L$.
• Theorem: $\lim\_{x \to x_0} f(x) = L \iff \lim\_{x \to x_0^+} f(x) = \lim\_{x \to x_0^-} f(x) = L$.

**Example 4:** Let $f(x) = \begin{cases} x^2 & \text{if } 0 < x < 1 \\\ x + 1 & \text{if } 1 \le x < 2. \end{cases}$ Find $\lim\_{x \to 1^-} f(x)$ and $\lim\_{x \to 1^+} f(x)$.

Solution to Example 4:
• For $0 < x < 1$, we have $f(x) = x^2$. Hence: $\lim\_{x \to 1^-} f(x) = \lim\_{x \to 1^-} x^2 = 1^2 = 1$.
• For $1 < x < 2$, we have $f(x) = x + 1$. Hence: $\lim\_{x \to 1^+} f(x) = \lim\_{x \to 1^+} (x + 1) = 1 + 1 = 2$.
• Remark: Since $\lim\_{x \to 1^-} f(x) = 1 \ne 2 = \lim\_{x \to 1^+} f(x)$, the limit $\lim\_{x \to 1} f(x)$ does not exist.

**Practice 2:** Let $f(x) = \begin{cases} -x & \text{if } x < 0 \\\ \sqrt{x} & \text{if } x \ge 0. \end{cases}$ Find $\lim\_{x \to 0^+} f(x)$, $\lim\_{x \to 0^-} f(x)$, and $\lim\_{x \to 0} f(x)$.

Solution to Practice 2:
• $\lim\_{x \to 0^+} f(x) = \lim\_{x \to 0^+} \sqrt{x} = 0$.
• $\lim\_{x \to 0^-} f(x) = \lim\_{x \to 0^-} (-x) = 0$.
• Since $\lim\_{x \to 0^+} f(x) = \lim\_{x \to 0^-} f(x) = 0$, we have $\lim\_{x \to 0} f(x) = 0$.

## Finite Limits of a Function at Infinity

<Youtube url="https://www.youtube.com/watch?v=example_gioi_han_tai_vo_cuc"/>

### a) Definitions and Rules

• Let $y = f(x)$ be defined on $(a; +\infty)$. We say that $f(x)$ has the limit $L$ as $x \to +\infty$ if for every sequence $(x_n)$ such that $x_n > a$ and $x_n \to +\infty$, we have $f(x_n) \to L$, denoted by $\lim\_{x \to +\infty} f(x) = L$.
• Analogous definitions apply to $\lim\_{x \to -\infty} f(x) = L$ on $(-\infty; b)$.
• The algebraic rules for evaluating finite limits at a point also hold for finite limits at infinity.
• Basic results: $\lim\_{x \to \pm\infty} c = c$; $\lim\_{x \to \pm\infty} \frac{1}{x^k} = 0$ ($k \in \mathbb{N}^*$).

### b) Examples and Practice on Limits at Infinity

**Example 6:** Evaluate $\lim\_{x \to -\infty} \frac{\sqrt{x^2 + 1}}{x}$.

Solution to Example 6:
• As $x \to -\infty$, we have $x < 0$, so $\sqrt{x^2} = |x| = -x \Rightarrow x = -\sqrt{x^2}$:
  $$\lim\_{x \to -\infty} \frac{\sqrt{x^2 + 1}}{x} = \lim\_{x \to -\infty} \left(-\sqrt{\frac{x^2 + 1}{x^2}}\right) = -\lim\_{x \to -\infty} \sqrt{1 + \frac{1}{x^2}} = -\sqrt{1 + 0} = -1.$$

**Practice 3:** Evaluate $\lim\_{x \to +\infty} \frac{\sqrt{x^2 + 2}}{x + 1}$.

Solution to Practice 3:
• As $x \to +\infty$, $x > 0$, hence $\sqrt{x^2} = x$. Dividing both numerator and denominator by $x$:
  $$\lim\_{x \to +\infty} \frac{\sqrt{x^2 + 2}}{x + 1} = \lim\_{x \to +\infty} \frac{\sqrt{1 + \frac{2}{x^2}}}{1 + \frac{1}{x}} = \frac{\sqrt{1 + 0}}{1 + 0} = 1.$$

## Infinite Limits of a Function

<Youtube url="https://www.youtube.com/watch?v=example_gioi_han_vo_cuc"/>

### a) Definition of Infinite Limits

• We say that $f(x)$ approaches $+\infty$ as $x \to x_0$ if for every sequence $(x_n) \subset (a; b) \setminus \\{x_0\\}$ with $x_n \to x_0$, we have $f(x_n) \to +\infty$, denoted by $\lim\_{x \to x_0} f(x) = +\infty$.
• Similar definitions apply to $\lim\_{x \to x_0} f(x) = -\infty$, one-sided limits $\lim\_{x \to x_0^\pm} f(x) = \pm\infty$, and limits at infinity $\lim\_{x \to \pm\infty} f(x) = \pm\infty$.
• Special limits: $\lim\_{x \to +\infty} x^k = +\infty$ ($k \in \mathbb{N}^*$); $\lim\_{x \to -\infty} x^k = +\infty$ if $k$ is even, and $-\infty$ if $k$ is odd.

### b) Rules for Evaluating Infinite Limits

• Rule for the limit of a product $f(x)g(x)$ when $\lim\_{x \to x_0} f(x) = L \ne 0$ and $\lim\_{x \to x_0} g(x) = \pm\infty$:
  + If $L > 0$ and $g(x) \to +\infty$, then $f(x)g(x) \to +\infty$; if $g(x) \to -\infty$, then $f(x)g(x) \to -\infty$.
  + If $L < 0$ and $g(x) \to +\infty$, then $f(x)g(x) \to -\infty$; if $g(x) \to -\infty$, then $f(x)g(x) \to +\infty$.
• Rule for the limit of a quotient $\frac{f(x)}{g(x)}$ when $\lim\_{x \to x_0} g(x) = 0$ ($g(x) \ne 0$):
  + If $\lim\_{x \to x_0} f(x) = L > 0$ and $g(x) > 0$, then $\lim\_{x \to x_0} \frac{f(x)}{g(x)} = +\infty$.
  + If $\lim\_{x \to x_0} f(x) = L > 0$ and $g(x) < 0$, then $\lim\_{x \to x_0} \frac{f(x)}{g(x)} = -\infty$.
  + Analogous rules apply when $L < 0$.

**Example 9:** Evaluate $\lim\_{x \to 0} \frac{x + 1}{x^2}$.

Solution to Example 9:
• The numerator approaches $\lim\_{x \to 0} (x + 1) = 1 > 0$.
• The denominator satisfies $\lim\_{x \to 0} x^2 = 0$ and $x^2 > 0$ for all $x \ne 0$.
• By the quotient rule for limits: $\lim\_{x \to 0} \frac{x + 1}{x^2} = +\infty$.

**Example 10:** Evaluate $\lim\_{x \to 1^+} \frac{1}{x(1 - x)}$ and $\lim\_{x \to 1^-} \frac{1}{x(1 - x)}$.

Solution to Example 10:
• Write $\frac{1}{x(1 - x)} = \frac{1}{x} \cdot \frac{1}{1 - x}$. We have $\lim\_{x \to 1} \frac{1}{x} = 1 > 0$.
• As $x \to 1^+$, $x > 1 \Rightarrow 1 - x < 0$ and approaches 0, so $\lim\_{x \to 1^+} \frac{1}{1 - x} = -\infty$.
  Thus, $\lim\_{x \to 1^+} \frac{1}{x(1 - x)} = -\infty$.
• As $x \to 1^-$, $x < 1 \Rightarrow 1 - x > 0$ and approaches 0, so $\lim\_{x \to 1^-} \frac{1}{1 - x} = +\infty$.
  Thus, $\lim\_{x \to 1^-} \frac{1}{x(1 - x)} = +\infty$.

**Practice 5:** Evaluate $\lim\_{x \to 2^+} \frac{2x - 1}{x - 2}$ and $\lim\_{x \to 2^-} \frac{2x - 1}{x - 2}$.

Solution to Practice 5:
• The numerator approaches $\lim\_{x \to 2} (2x - 1) = 3 > 0$.
• As $x \to 2^+$, the denominator $x - 2 > 0$ and approaches 0, so $\lim\_{x \to 2^+} \frac{2x - 1}{x - 2} = +\infty$.
• As $x \to 2^-$, the denominator $x - 2 < 0$ and approaches 0, so $\lim\_{x \to 2^-} \frac{2x - 1}{x - 2} = -\infty$.

## Applications and Exercises

### a) Real-World Applications and Mathematical Modeling

**Application 1 (Einstein's Special Relativity):** In Einstein's Theory of Special Relativity, the mass of an object moving with velocity $v$ is given by $m = \frac{m_0}{\sqrt{1 - \frac{v^2}{c^2}}}$, where $m_0$ is the rest mass and $c$ is the speed of light. What happens to the mass of the object as its velocity approaches the speed of light?

Solution to Application 1:
• Consider $m$ as a function of $v$ defined on the half-open interval $[0; c)$.
• As $v$ approaches $c$ from the left ($v \to c^-$), $\frac{v^2}{c^2} \to 1^-$, so $\sqrt{1 - \frac{v^2}{c^2}} \to 0^+$ (approaching 0 through positive values).
• Since the numerator $m_0 > 0$ is constant, we have:
  $$\lim\_{v \to c^-} m(v) = \lim\_{v \to c^-} \frac{m_0}{\sqrt{1 - \frac{v^2}{c^2}}} = +\infty.$$
• Conclusion: The mass $m$ of the object increases without bound (approaches $+\infty$) as its speed nears the speed of light.

**Application 2 (Geometric Motion):** Consider a right triangle $OAB$ with vertices $A(a; 0)$ ($a > 0$) and $B(0; 1)$. The altitude $OH$ has length $h$.
a) Express $h$ in terms of $a$.
b) As point $A$ moves toward the origin $O$, how does point $H$ change? Explain why.
c) As point $A$ moves toward infinity along the positive direction of the x-axis, how does point $H$ change? Explain why.

Solution to Application 2:
• a) In the right triangle $OAB$ with right angle at $O$, the geometric relation for the altitude gives:
  $$\frac{1}{h^2} = \frac{1}{OA^2} + \frac{1}{OB^2} = \frac{1}{a^2} + \frac{1}{1^2} = \frac{1 + a^2}{a^2} \implies h = \frac{a}{\sqrt{a^2 + 1}}.$$
• b) As point $A$ moves toward $O$, meaning $a \to 0^+$:
  $$\lim\_{a \to 0^+} h = \lim\_{a \to 0^+} \frac{a}{\sqrt{a^2 + 1}} = \frac{0}{1} = 0.$$
  Thus, the length of $OH$ approaches 0, meaning point $H$ converges to the origin $O$.
• c) As point $A$ moves toward infinity along the positive x-axis, meaning $a \to +\infty$:
  $$\lim\_{a \to +\infty} h = \lim\_{a \to +\infty} \frac{a}{\sqrt{a^2 + 1}} = \lim\_{a \to +\infty} \frac{1}{\sqrt{1 + \frac{1}{a^2}}} = 1.$$
  In this case, the segment $OH$ approaches length 1, line $AB$ becomes nearly parallel to the x-axis, and point $H$ converges to $B(0; 1)$.

### b) End-of-Lesson Exercises

**Exercise 5.7:** Given two functions $f(x) = \frac{x^2 - 1}{x - 1}$ and $g(x) = x + 1$. Which of the following statements is true?
a) $f(x) = g(x)$;
b) $\lim\_{x \to 1} f(x) = \lim\_{x \to 1} g(x)$.

Solution to Exercise 5.7:
• Statement a) is FALSE because the two functions have different domains: $D_f = \mathbb{R} \setminus \\{1\\}$, whereas $D_g = \mathbb{R}$.
• Statement b) is TRUE because for all $x \ne 1$, $f(x) = \frac{(x - 1)(x + 1)}{x - 1} = x + 1 = g(x)$. Thus, $\lim\_{x \to 1} f(x) = \lim\_{x \to 1} (x + 1) = 2$ and $\lim\_{x \to 1} g(x) = \lim\_{x \to 1} (x + 1) = 2$.

**Exercise 5.8:** Evaluate the following limits:
a) $\lim\_{x \to 0} \frac{(x + 2)^2 - 4}{x}$;
b) $\lim\_{x \to 0} \frac{\sqrt{x^2 + 9} - 3}{x^2}$.

Solution to Exercise 5.8:
• a) $\lim\_{x \to 0} \frac{(x + 2)^2 - 4}{x} = \lim\_{x \to 0} \frac{x^2 + 4x + 4 - 4}{x} = \lim\_{x \to 0} \frac{x(x + 4)}{x} = \lim\_{x \to 0} (x + 4) = 4$.
• b) Multiplying by the conjugate $(\sqrt{x^2 + 9} + 3)$:
  $$\lim\_{x \to 0} \frac{\sqrt{x^2 + 9} - 3}{x^2} = \lim\_{x \to 0} \frac{(x^2 + 9) - 9}{x^2(\sqrt{x^2 + 9} + 3)} = \lim\_{x \to 0} \frac{x^2}{x^2(\sqrt{x^2 + 9} + 3)} = \lim\_{x \to 0} \frac{1}{\sqrt{x^2 + 9} + 3} = \frac{1}{3 + 3} = \frac{1}{6}.$$

**Exercise 5.9:** Let $H(t) = \begin{cases} 0 & \text{if } t < 0 \\\ 1 & \text{if } t \ge 0 \end{cases}$ (Heaviside step function). Compute $\lim\_{t \to 0^+} H(t)$ and $\lim\_{t \to 0^-} H(t)$.

Solution to Exercise 5.9:
• As $t \to 0^+$, $t > 0 \Rightarrow H(t) = 1$. Hence, $\lim\_{t \to 0^+} H(t) = 1$.
• As $t \to 0^-$, $t < 0 \Rightarrow H(t) = 0$. Hence, $\lim\_{t \to 0^-} H(t) = 0$.

**Exercise 5.10:** Evaluate the one-sided limits:
a) $\lim\_{x \to 1^+} \frac{x - 2}{x - 1}$;
b) $\lim\_{x \to 4^-} \frac{x^2 - x + 1}{4 - x}$.

Solution to Exercise 5.10:
• a) As $x \to 1^+$, the numerator $x - 2 \to 1 - 2 = -1 < 0$; the denominator $x - 1 > 0$ and approaches 0. Therefore, $\lim\_{x \to 1^+} \frac{x - 2}{x - 1} = -\infty$.
• b) As $x \to 4^-$, the numerator $x^2 - x + 1 \to 16 - 4 + 1 = 13 > 0$; the denominator $4 - x > 0$ and approaches 0. Therefore, $\lim\_{x \to 4^-} \frac{x^2 - x + 1}{4 - x} = +\infty$.

**Exercise 5.11:** Given the function $g(x) = \frac{x^2 - 5x + 6}{|x - 2|}$. Find $\lim\_{x \to 2^+} g(x)$ and $\lim\_{x \to 2^-} g(x)$.

Solution to Exercise 5.11:
• Note that $x^2 - 5x + 6 = (x - 2)(x - 3)$.
• As $x \to 2^+$, $x > 2 \Rightarrow |x - 2| = x - 2$, so:
  $$\lim\_{x \to 2^+} g(x) = \lim\_{x \to 2^+} \frac{(x - 2)(x - 3)}{x - 2} = \lim\_{x \to 2^+} (x - 3) = 2 - 3 = -1.$$
• As $x \to 2^-$, $x < 2 \Rightarrow |x - 2| = -(x - 2)$, so:
  $$\lim\_{x \to 2^-} g(x) = \lim\_{x \to 2^-} \frac{(x - 2)(x - 3)}{-(x - 2)} = \lim\_{x \to 2^-} [-(x - 3)] = -(2 - 3) = 1.$$

**Exercise 5.12:** Evaluate the following limits:
a) $\lim\_{x \to +\infty} \frac{1 - 2x}{\sqrt{x^2 + 1}}$;
b) $\lim\_{x \to +\infty} (\sqrt{x^2 + x + 2} - x)$.

Solution to Exercise 5.12:
• a) As $x \to +\infty$, $x > 0$, so $\sqrt{x^2} = x$. Dividing numerator and denominator by $x$:
  $$\lim\_{x \to +\infty} \frac{1 - 2x}{\sqrt{x^2 + 1}} = \lim\_{x \to +\infty} \frac{\frac{1}{x} - 2}{\sqrt{1 + \frac{1}{x^2}}} = \frac{0 - 2}{\sqrt{1 + 0}} = -2.$$
• b) Multiplying by the conjugate $(\sqrt{x^2 + x + 2} + x)$:
  $$\lim\_{x \to +\infty} (\sqrt{x^2 + x + 2} - x) = \lim\_{x \to +\infty} \frac{(x^2 + x + 2) - x^2}{\sqrt{x^2 + x + 2} + x} = \lim\_{x \to +\infty} \frac{x + 2}{\sqrt{x^2 + x + 2} + x}$$
  Dividing numerator and denominator by $x$:
  $$= \lim\_{x \to +\infty} \frac{1 + \frac{2}{x}}{\sqrt{1 + \frac{1}{x} + \frac{2}{x^2}} + 1} = \frac{1 + 0}{\sqrt{1 + 0 + 0} + 1} = \frac{1}{2}.$$

**Exercise 5.13:** Given the function $f(x) = \frac{2}{(x - 1)(x - 2)}$. Find $\lim\_{x \to 2^+} f(x)$ and $\lim\_{x \to 2^-} f(x)$.

Solution to Exercise 5.13:
• As $x \to 2$, the numerator is $2 > 0$ and $\lim\_{x \to 2} (x - 1) = 1 > 0$, hence $\lim\_{x \to 2} \frac{2}{x - 1} = 2 > 0$.
• As $x \to 2^+$, $x > 2 \Rightarrow x - 2 > 0$ and approaches 0. Therefore, $\lim\_{x \to 2^+} f(x) = +\infty$.
• As $x \to 2^-$, $x < 2 \Rightarrow x - 2 < 0$ and approaches 0. Therefore, $\lim\_{x \to 2^-} f(x) = -\infty$.
