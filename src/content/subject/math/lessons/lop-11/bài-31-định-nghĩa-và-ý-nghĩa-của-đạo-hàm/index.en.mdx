## Definition of the Derivative of a Function

### a) Derivative at a Point

Let the function $y = f(x)$ be defined on the open interval $(a; b)$ and let $x_0 \in (a; b)$.
If the finite limit exists:
$$\lim\_{x \to x_0} \frac{f(x) - f(x_0)}{x - x_0}$$
then this limit is called the derivative of the function $y = f(x)$ at the point $x_0$, denoted by $f'(x_0)$ (or $y'(x_0)$), that is:
$$f'(x_0) = \lim\_{x \to x_0} \frac{f(x) - f(x_0)}{x - x_0}$$
Setting the increment of the argument as $h = x - x_0$, we obtain the equivalent formula:
$$f'(x_0) = \lim\_{h \to 0} \frac{f(x_0 + h) - f(x_0)}{h}$$
Steps to compute the derivative at a point using the definition:
1\. Compute the difference $f(x) - f(x_0)$;
2\. Form and simplify the difference quotient $\frac{f(x) - f(x_0)}{x - x_0}$ for $x \ne x_0$;
3\. Evaluate the limit $\lim\_{x \to x_0} \frac{f(x) - f(x_0)}{x - x_0}$.

### b) Examples and Practice on Computing Derivatives at a Point

**Example 1:** Compute the derivative of the function $y = f(x) = x^2 + 2x$ at the point $x_0 = 1$.

Solution to Example 1:
• We have: $f(x) - f(1) = (x^2 + 2x) - 3 = x^2 + 2x - 3 = (x - 1)(x + 3)$.
• For $x \ne 1$, the difference quotient is:
  $$\frac{f(x) - f(1)}{x - 1} = \frac{(x - 1)(x + 3)}{x - 1} = x + 3.$$
• Evaluating the limit:
  $$f'(1) = \lim\_{x \to 1} \frac{f(x) - f(1)}{x - 1} = \lim\_{x \to 1} (x + 3) = 4.$$
• Thus, $f'(1) = 4$.

**Practice 1:** Compute the derivative of the function $y = -x^2 + 2x + 1$ at the point $x_0 = -1$.

Solution to Practice 1:
• At $x_0 = -1$, we have $f(-1) = -(-1)^2 + 2(-1) + 1 = -2$.
• Consider the difference:
  $$f(x) - f(-1) = (-x^2 + 2x + 1) - (-2) = -x^2 + 2x + 3 = -(x + 1)(x - 3).$$
• Form the difference quotient for $x \ne -1$:
  $$\frac{f(x) - f(-1)}{x - (-1)} = \frac{-(x + 1)(x - 3)}{x + 1} = -(x - 3) = 3 - x.$$
• Evaluating the limit:
  $$f'(-1) = \lim\_{x \to -1} (3 - x) = 3 - (-1) = 4.$$
• Thus, $f'(-1) = 4$.

### c) Derivative on an Interval

A function $y = f(x)$ is said to be differentiable on the interval $(a; b)$ if it has a derivative $f'(x)$ at every point $x$ in that interval, denoted by $y' = f'(x)$.
Basic differentiation formulas derived from the definition:
• $(c)' = 0$ (where $c$ is a constant);
• $(x)' = 1$;
• $(cx^2)' = 2cx$ (where $c$ is a constant).

**Example 2:** Find the derivative of the function $y = cx^2$ (where $c$ is a constant) on $\mathbb{R}$.

Solution to Example 2:
• For any arbitrary point $x_0$, we have:
  $$f'(x_0) = \lim\_{x \to x_0} \frac{cx^2 - cx_0^2}{x - x_0} = \lim\_{x \to x_0} \frac{c(x - x_0)(x + x_0)}{x - x_0} = \lim\_{x \to x_0} c(x + x_0) = 2cx_0.$$
• Therefore, the derivative of the function $y = cx^2$ is $y' = 2cx$.

## Geometric and Physical Interpretations of the Derivative

### a) Geometric Interpretation and Tangent Line Equation

• Geometric Interpretation: The derivative $f'(x_0)$ represents the slope of the tangent line to the graph of the function $y = f(x)$ at the point of tangency $P(x_0; f(x_0))$.
• Tangent Line Equation: If the function $y = f(x)$ is differentiable at $x_0$, the equation of the tangent line to the graph at $P(x_0; y_0)$ (where $y_0 = f(x_0)$) is:
$$y - y_0 = f'(x_0)(x - x_0)$$

**Example 5:** Write the equation of the tangent line to the parabola $(P): y = 3x^2$ at the point with abscissa $x_0 = 1$.

Solution to Example 5:
• We have $y' = 6x$. The slope of the tangent line at $x_0 = 1$ is $k = f'(1) = 6 \cdot 1 = 6$.
• The ordinate of the point of tangency is $y_0 = f(1) = 3 \cdot 1^2 = 3$.
• The equation of the tangent line is:
  $$y - 3 = 6(x - 1) \iff y = 6x - 3.$$

**Practice 4:** Write the equation of the tangent line to the parabola $(P): y = -2x^2$ at the point with abscissa $x_0 = -1$.

Solution to Practice 4:
• The derivative is $y' = -4x$. The slope of the tangent line at $x_0 = -1$ is $k = y'(-1) = -4(-1) = 4$.
• The ordinate of the point of tangency is $y_0 = -2(-1)^2 = -2$.
• The equation of the tangent line is:
  $$y - (-2) = 4(x - (-1)) \iff y + 2 = 4(x + 1) \iff y = 4x + 2.$$

### b) Physical Interpretation of the Derivative

• Instantaneous Velocity: If the equation of motion of an object is $s = s(t)$, then the instantaneous velocity of the object at time $t_0$ is the derivative of position with respect to time evaluated at that instant:
$$v(t_0) = s'(t_0)$$
• Instantaneous Electric Current: If the electric charge passing through a conductor is $Q = Q(t)$, then the instantaneous current at time $t_0$ is:
$$I(t_0) = Q'(t_0)$$

## Applications and Exercises

### a) Real-World Applications

**Application 1 (Free Fall Velocity from Landmark 81):** A ball is dropped in free fall from the observation deck on the roof of Landmark 81 (height 461.3 m) to the ground according to the equation $s(t) = \frac{1}{2}gt^2$ with $g = 9.8\text{ m/s}^2$. Calculate the velocity of the ball when it strikes the ground (neglecting air resistance, rounding the result to one decimal place).

Solution to Application 1:
• The instantaneous velocity of the ball at time $t$ is:
  $$v(t) = s'(t) = gt = 9.8t\text{ (m/s).}$$
• The ball strikes the ground when $s(t) = 461.3\text{ m} \iff 4.9t^2 = 461.3 \iff t = \sqrt{\frac{461.3}{4.9}} \approx 9.703\text{ (seconds).}$$
• The velocity upon impact is:
  $$v = 9.8 \cdot \sqrt{\frac{461.3}{4.9}} \approx 95.1\text{ (m/s)} \approx 342.4\text{ (km/h).}$$

**Application 2 (Slope of a Steel Overpass):** A parabolic overpass spans two points 400 m apart with its apex at the origin $y = -ax^2$ ($a > 0$). The slope of the bridge surface at any point does not exceed $10^{\circ}$. Calculate the maximum height from the apex of the bridge to the roadway.

Solution to Application 2:
• Set up a coordinate system where the apex is at the origin $O(0; 0)$ and the roadway is horizontal beneath it. Thus, $-200 \le x \le 200$.
• The slope of the tangent line at abscissa $x$ is $k = y' = -2ax$. The inclination/slope magnitude at that point is $|k| = 2a|x|$.
• The maximum slope occurs at the two ends $x = \pm 200$:
  $$\max |k| = 2a \cdot 200 = 400a.$$
• Since the slope angle does not exceed $10^{\circ}$, we have $400a \le \tan 10^{\circ} \implies a \le \frac{\tan 10^{\circ}}{400}$.
• The height from the apex to the roadway is the distance from $y(0) = 0$ to $y(200) = -a(200)^2 = -40\\,000a$:
  $$h = 40\\,000a \le 40\\,000 \cdot \frac{\tan 10^{\circ}}{400} = 100 \cdot \tan 10^{\circ} \approx 100 \cdot 0.1763 = 17.6\text{ (m).}$$
• Thus, the maximum allowable height from the bridge apex to the roadway is approximately 17.6 m.

### b) End-of-Lesson Exercises

**Exercise 9.1:** Compute the derivative of the following functions using the definition:
a) $y = x^2 - x$ at $x_0 = 1$;
b) $y = -x^3$ at $x_0 = -1$.

Solution to Exercise 9.1:
• a) At $x_0 = 1$, $f(1) = 0$. We have:
  $$f'(1) = \lim\_{x \to 1} \frac{(x^2 - x) - 0}{x - 1} = \lim\_{x \to 1} \frac{x(x - 1)}{x - 1} = \lim\_{x \to 1} x = 1.$$
• b) At $x_0 = -1$, $f(-1) = -(-1)^3 = 1$. We have:
  $$f'(-1) = \lim\_{x \to -1} \frac{-x^3 - 1}{x - (-1)} = \lim\_{x \to -1} \frac{-(x^3 + 1)}{x + 1} = \lim\_{x \to -1} \frac{-(x + 1)(x^2 - x + 1)}{x + 1} = \lim\_{x \to -1} -(x^2 - x + 1) = -3.$$

**Exercise 9.2:** Using the definition, find the derivative of the following functions on their domains:
a) $y = kx^2 + c$ (where $k, c$ are constants);
b) $y = x^3$.

Solution to Exercise 9.2:
• a) For any arbitrary point $x_0$:
  $$y'(x_0) = \lim\_{x \to x_0} \frac{(kx^2 + c) - (kx_0^2 + c)}{x - x_0} = \lim\_{x \to x_0} \frac{k(x^2 - x_0^2)}{x - x_0} = \lim\_{x \to x_0} k(x + x_0) = 2kx_0.$$
  Thus, $(kx^2 + c)' = 2kx$.
• b) For any arbitrary point $x_0$:
  $$y'(x_0) = \lim\_{x \to x_0} \frac{x^3 - x_0^3}{x - x_0} = \lim\_{x \to x_0} (x^2 + x x_0 + x_0^2) = 3x_0^2.$$
  Thus, $(x^3)' = 3x^2$.

**Exercise 9.3:** Write the equation of the tangent line to the parabola $y = -x^2 + 4x$ given that:
a) The point of tangency has abscissa $x_0 = 1$;
b) The point of tangency has ordinate $y_0 = 0$.

Solution to Exercise 9.3:
• Derivative: $y' = -2x + 4$.
• a) With $x_0 = 1 \implies y_0 = -1^2 + 4(1) = 3$. The slope is $k = y'(1) = -2(1) + 4 = 2$.
  The tangent line equation is: $y - 3 = 2(x - 1) \iff y = 2x + 1$.
• b) With $y_0 = 0 \iff -x^2 + 4x = 0 \iff x = 0$ or $x = 4$.
  - At $(0; 0)$: $k = y'(0) = 4 \implies$ Tangent equation is $y = 4x$.
  - At $(4; 0)$: $k = y'(4) = -2(4) + 4 = -4 \implies$ Tangent equation is $y - 0 = -4(x - 4) \iff y = -4x + 16$.

**Exercise 9.4:** An object is launched vertically upward from the ground with altitude equation $h(t) = 19.6t - 4.9t^2$ (meters). Find the velocity of the object when it hits the ground.

Solution to Exercise 9.4:
• The instantaneous velocity at time $t$ is the derivative of height: $v(t) = h'(t) = 19.6 - 9.8t\text{ (m/s)}$.
• The object hits the ground when $h(t) = 0 \iff 19.6t - 4.9t^2 = 0 \iff t(19.6 - 4.9t) = 0$.
  Since $t > 0$, the impact time is $t = \frac{19.6}{4.9} = 4\text{ (seconds)}$.
• The velocity upon impact is:
  $$v(4) = 19.6 - 9.8(4) = 19.6 - 39.2 = -19.6\text{ (m/s).}$$
• The negative sign indicates downward motion toward the ground, with speed upon impact equal to $19.6\text{ m/s}$.
