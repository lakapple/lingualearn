## Equation of a Circle

<Youtube url="https://www.youtube.com/watch?v=example_phuong_trinh_duong_tron"/>

### a) Standard Form of the Equation of a Circle

Definition and Equation:
In the Cartesian coordinate plane $Oxy$, the circle $(C)$ with center $I(a; b)$ and radius $R$ is the locus of all points $M(x; y)$ satisfying $IM = R$.
We have: $IM = \sqrt{(x - a)^2 + (y - b)^2} = R \Leftrightarrow (x - a)^2 + (y - b)^2 = R^2$.
The equation:
$$(x - a)^2 + (y - b)^2 = R^2 \quad (1)$$
is called the standard equation of the circle $(C)$ with center $I(a; b)$ and radius $R$.

Special Case: A circle $(C)$ centered at the origin $O(0; 0)$ with radius $R$ has the equation:
$$x^2 + y^2 = R^2$$

### b) General Form of the Equation of a Circle

Expanding equation $(1)$, we obtain:
$$x^2 + y^2 - 2ax - 2by + (a^2 + b^2 - R^2) = 0$$
Setting $c = a^2 + b^2 - R^2$, the equation becomes:
$$x^2 + y^2 - 2ax - 2by + c = 0 \quad (2)$$

Condition for a Quadratic Equation to Represent a Circle:
An equation of the form $x^2 + y^2 - 2ax - 2by + c = 0$ represents a real circle $(C)$ if and only if:
$$a^2 + b^2 - c > 0$$
Under this condition, the circle $(C)$ has:
• Center: $I(a; b)$;
• Radius: $R = \sqrt{a^2 + b^2 - c}$.

### c) Illustrative Examples and Practice on Circle Equations

**Example 1:** Find the center and radius of the circle $(C): (x - 2)^2 + (y + 3)^2 = 16$. Write the equation of the circle $(C')$ with center $J(2; -1)$ whose radius is twice that of circle $(C)$.

Solution for Example 1:
• Rewriting $(C)$ in standard form: $(x - 2)^2 + [y - (-3)]^2 = 4^2$. Thus, $(C)$ has center $I(2; -3)$ and radius $R = 4$.
• The circle $(C')$ has center $J(2; -1)$ and radius $R' = 2R = 2 \cdot 4 = 8$. Its equation is:
$$(x - 2)^2 + (y + 1)^2 = 8^2 \Leftrightarrow (x - 2)^2 + (y + 1)^2 = 64.$$

**Practice 1:** Find the center and radius of the circle $(C): (x + 2)^2 + (y - 4)^2 = 7$.

Solution for Practice 1:
• Rewriting the equation: $[x - (-2)]^2 + (y - 4)^2 = (\sqrt{7})^2$.
• Circle $(C)$ has center $I(-2; 4)$ and radius $R = \sqrt{7}$.

**Practice 2:** Determine which of the following equations represent a circle. If so, find the center and radius:
a) $x^2 - y^2 - 2x + 4y - 1 = 0$;
b) $x^2 + y^2 - 2x + 4y + 6 = 0$;
c) $x^2 + y^2 + 6x - 4y + 2 = 0$.

Solution for Practice 2:
• a) The coefficients of $x^2$ and $y^2$ are not equal (it contains $-y^2$), so it is not a circle.
• b) Here $a = 1$, $b = -2$, and $c = 6$. Evaluating $a^2 + b^2 - c = 1^2 + (-2)^2 - 6 = 5 - 6 = -1 < 0$. The condition $a^2 + b^2 - c > 0$ fails, so it is not a circle.
• c) Here $a = -3$, $b = 2$, and $c = 2$. Evaluating $a^2 + b^2 - c = (-3)^2 + 2^2 - 2 = 9 + 4 - 2 = 11 > 0$. Therefore, this is a circle with center $I(-3; 2)$ and radius $R = \sqrt{11}$.

**Example 3:** Write the equation of the circle $(C)$ passing through three points $A(2; 0)$, $B(0; 4)$, and $C(-7; 3)$.

Solution for Example 3:
• Method 1 (Intersection of Perpendicular Bisectors):
  + The midpoint of $AB$ is $M(1; 2)$, with vector $\vec{AB} = (-2; 4) = -2(1; -2)$. The perpendicular bisector $\Delta_1$ of $AB$ passes through $M(1; 2)$ with normal vector $\vec{n}\_1 = (1; -2)$: $1(x - 1) - 2(y - 2) = 0 \Leftrightarrow x - 2y + 3 = 0$.
  + The midpoint of $AC$ is $N\left(-\frac{5}{2}; \frac{3}{2}\right)$, with vector $\vec{AC} = (-9; 3) = -3(3; -1)$. The perpendicular bisector $\Delta_2$ of $AC$ passes through $N$ with normal vector $\vec{n}\_2 = (3; -1)$: $3\left(x + \frac{5}{2}\right) - 1\left(y - \frac{3}{2}\right) = 0 \Leftrightarrow 3x - y + 9 = 0$.
  + The center $I$ is the intersection of $\Delta_1$ and $\Delta_2$: $\begin{cases} x - 2y + 3 = 0 \\\ 3x - y + 9 = 0 \end{cases} \Leftrightarrow \begin{cases} x = -3 \\\ y = 0 \end{cases} \Rightarrow I(-3; 0)$.
  + Radius: $R = IA = \sqrt{(2 - (-3))^2 + (0 - 0)^2} = 5$.
  + Therefore, the equation of $(C)$ is: $(x + 3)^2 + y^2 = 25$.
• Method 2 (General Form):
  + Let the equation of $(C)$ be: $x^2 + y^2 - 2ax - 2by + c = 0$.
  + Since $A(2; 0), B(0; 4), C(-7; 3) \in (C)$, we set up the linear system:
$$\begin{cases} 4 - 4a + c = 0 \\\ 16 - 8b + c = 0 \\\ 58 + 14a - 6b + c = 0 \end{cases} \Leftrightarrow \begin{cases} 4a - c = 4 \\\ 8b - c = 16 \\\ 14a - 6b + c = -58 \end{cases} \Leftrightarrow \begin{cases} a = -3 \\\ b = 0 \\\ c = -16 \end{cases}$$
  + Thus, the circle equation is: $x^2 + y^2 + 6x - 16 = 0 \Leftrightarrow (x + 3)^2 + y^2 = 25$.

**Practice 3:** Write the equation of the circle $(C)$ passing through three points $M(4; -5)$, $N(2; -1)$, and $P(3; -8)$.

Solution for Practice 3:
• Let the general equation of $(C)$ be: $x^2 + y^2 - 2ax - 2by + c = 0$.
• Since $M, N, P \in (C)$, their coordinates satisfy the system:
$$\begin{cases} 4^2 + (-5)^2 - 8a + 10b + c = 0 \\\ 2^2 + (-1)^2 - 4a + 2b + c = 0 \\\ 3^2 + (-8)^2 - 6a + 16b + c = 0 \end{cases} \Leftrightarrow \begin{cases} -8a + 10b + c = -41 \\\ -4a + 2b + c = -5 \\\ -6a + 16b + c = -73 \end{cases} \Leftrightarrow \begin{cases} a = 7 \\\ b = -5 \\\ c = 33 \end{cases}$$
• Verifying the condition: $a^2 + b^2 - c = 7^2 + (-5)^2 - 33 = 49 + 25 - 33 = 41 > 0$.
• Therefore, the equation of $(C)$ is: $x^2 + y^2 - 14x + 10y + 33 = 0$ or $(x - 7)^2 + (y + 5)^2 = 41$.

## Tangent Line to a Circle

<Youtube url="https://www.youtube.com/watch?v=example_tiep_tuyen_duong_tron"/>

### a) Equation of a Tangent Line at a Point

Theorem: Let $M(x_0; y_0)$ be a point lying on the circle $(C): (x - a)^2 + (y - b)^2 = R^2$ centered at $I(a; b)$ with radius $R$.
The tangent line $\Delta$ to the circle $(C)$ at the point of tangency $M$ is perpendicular to the radius $IM$. Hence, it takes the vector $\vec{MI} = (a - x_0; b - y_0)$ (or $\vec{IM} = (x_0 - a; y_0 - b)$) as its normal vector.
The equation of the tangent line $\Delta$ at $M(x_0; y_0)$ is:
$$(x_0 - a)(x - x_0) + (y_0 - b)(y - y_0) = 0$$
or equivalently:
$$(a - x_0)(x - x_0) + (b - y_0)(y - y_0) = 0$$

### b) Illustrative Examples and Practice on Tangent Lines

**Example 4:** Given the circle $(C): (x + 1)^2 + (y - 3)^2 = 5$. Does point $M(0; 1)$ lie on $(C)$? If so, write the equation of the tangent line to $(C)$ at $M$.

Solution for Example 4:
• Substituting $M(0; 1)$ into the left side of $(C)$: $(0 + 1)^2 + (1 - 3)^2 = 1^2 + (-2)^2 = 1 + 4 = 5$, which matches the right side. Hence, $M(0; 1) \in (C)$.
• Circle $(C)$ has center $I(-1; 3)$. The normal vector of the tangent line at $M$ is $\vec{MI} = (-1 - 0; 3 - 1) = (-1; 2)$.
• The equation of the tangent line at $M(0; 1)$ is:
$$-1(x - 0) + 2(y - 1) = 0 \Leftrightarrow -x + 2y - 2 = 0 \Leftrightarrow x - 2y + 2 = 0.$$

**Practice 4:** Given the circle $(C): x^2 + y^2 - 2x + 4y + 1 = 0$. Write the equation of the tangent line $\Delta$ to $(C)$ at point $N(1; 0)$.

Solution for Practice 4:
• Checking point $N$: $1^2 + 0^2 - 2(1) + 4(0) + 1 = 0$, so $N \in (C)$.
• The circle has $a = 1, b = -2$, giving center $I(1; -2)$.
• A normal vector to the tangent line at $N$ is $\vec{IN} = (1 - 1; 0 - (-2)) = (0; 2)$, or simply $\vec{n} = (0; 1)$.
• The equation of the tangent line $\Delta$ at $N(1; 0)$ is:
$$0(x - 1) + 1(y - 0) = 0 \Leftrightarrow y = 0$$
(The tangent line is the $x$-axis itself).

## Applications and Exercises

### a) Real-World Applications

**Application 1 (Jacuzzi Design in a Swimming Pool):** Inside a swimming pool, planners intend to install two identical semicircular jacuzzis and one full circular jacuzzi for bathers to relax against. Determine the radii of the jacuzzis such that the total perimeter of the three jacuzzis is $32\text{ m}$ while the total pool surface area occupied is minimized (use $\pi \approx 3.14$, round to two decimal places).

Solution for Application 1:
• Let $x\text{ (m)}$ ($x > 0$) be the radius of the circular jacuzzi, and $y\text{ (m)}$ ($y > 0$) be the radius of each semicircular jacuzzi.
  + Perimeter of the full circular pool: $C_1 = 2\pi x$.
  + Perimeter of each semicircular pool (semicircular arc plus diameter): $C_2 = \pi y + 2y = (\pi + 2)y$.
  + Total perimeter of 1 circular and 2 semicircular pools:
$$C = 2\pi x + 2(\pi + 2)y = 32 \Leftrightarrow \pi x + (\pi + 2)y = 16$$
  Substituting $\pi = 3.14$: $3.14x + 5.14y = 16 \Leftrightarrow 1.57x + 2.57y - 8 = 0$ (line $\Delta$).
• Total surface area occupied by the three jacuzzis:
$$S = \pi x^2 + 2\left(\frac{1}{2}\pi y^2\right) = \pi x^2 + \pi y^2 = \pi(x^2 + y^2) \Rightarrow x^2 + y^2 = \frac{S}{\pi} = \frac{S}{3.14}$$
• In the coordinate plane $Oxy$, the point $M(x; y)$ with $x > 0, y > 0$ is an intersection point of the line $\Delta: 1.57x + 2.57y - 8 = 0$ and the circle $(C): x^2 + y^2 = R^2$ with radius $R = \sqrt{\frac{S}{3.14}}$.
• The area $S$ is minimized if and only if the radius $R$ is minimized, which occurs when the circle $(C)$ is tangent to the line $\Delta$ in the first quadrant. In that case, $R$ equals the distance from the origin $O(0; 0)$ to line $\Delta$:
$$R\_{\min} = d(O, \Delta) = \frac{|-8|}{\sqrt{1.57^2 + 2.57^2}} = \frac{8}{\sqrt{2.4649 + 6.6049}} = \frac{8}{\sqrt{9.0698}} \approx \frac{8}{3.0116} \approx 2.66\text{ (m)}$$
• The coordinates of the tangency point $M(x; y)$, being the orthogonal projection of $O$ onto $\Delta$, satisfy:
$$\begin{cases} 1.57x + 2.57y - 8 = 0 \\\ 2.57x - 1.57y = 0 \end{cases} \Leftrightarrow \begin{cases} x \approx 1.38\text{ (m)} \\\ y \approx 2.27\text{ (m)} \end{cases}$$
• Conclusion: The radius of the circular jacuzzi is approximately $1.38\text{ m}$, and the radius of the two semicircular jacuzzis is approximately $2.27\text{ m}$.

**Application 2 (Particle Tangential Escape from Circular Motion):** In the coordinate plane $Oxy$, a particle moves rapidly along a circular orbit $x^2 + y^2 = 25$. Upon reaching point $M(3; 4)$, the particle detaches from its circular path and travels along the tangent line. Along which straight line does the particle move immediately after detaching?

Solution for Application 2:
• Circle $(C): x^2 + y^2 = 25$ is centered at $O(0; 0)$ with radius $R = 5$.
• Point $M(3; 4)$ lies on $(C)$ because $3^2 + 4^2 = 25$. Upon detachment, the particle moves along the tangent line to $(C)$ at $M$.
• The tangent line at $M(3; 4)$ takes the radius vector $\vec{OM} = (3; 4)$ as its normal vector.
• The equation of the tangential trajectory line is:
$$3(x - 3) + 4(y - 4) = 0 \Leftrightarrow 3x - 9 + 4y - 16 = 0 \Leftrightarrow 3x + 4y - 25 = 0.$$
• Conclusion: Immediately after detachment, the particle moves along the straight line $3x + 4y - 25 = 0$.

**Exercise 7.18 (Parametric Circular Motion):** The motion of an object over a period of 180 minutes is represented in the coordinate plane: at time $t$ ($0 \le t \le 180$), the position of the object has coordinates $(x; y) = (2 + \sin t^\circ; 4 + \cos t^\circ)$.
a) Find the initial and terminal positions of the object.
b) Determine the trajectory path of the object.

Solution for Exercise 7.18:
• a) Initial position at $t = 0$:
  $x(0) = 2 + \sin 0^\circ = 2$; $y(0) = 4 + \cos 0^\circ = 4 + 1 = 5$. Thus, the starting point is $A(2; 5)$.
  Terminal position at $t = 180$:
  $x(180) = 2 + \sin 180^\circ = 2$; $y(180) = 4 + \cos 180^\circ = 4 - 1 = 3$. Thus, the endpoint is $B(2; 3)$.
• b) From the parametric coordinates:
$$\begin{cases} x - 2 = \sin t^\circ \\\ y - 4 = \cos t^\circ \end{cases}$$
  Squaring and adding both equations, using the fundamental trigonometric identity $\sin^2 t^\circ + \cos^2 t^\circ = 1$:
$$(x - 2)^2 + (y - 4)^2 = \sin^2 t^\circ + \cos^2 t^\circ = 1$$
  Since $0 \le t \le 180$, we have $\sin t^\circ \ge 0 \Rightarrow x - 2 \ge 0 \Leftrightarrow x \ge 2$.
  Conclusion: The trajectory of the object is the right semicircle centered at $I(2; 4)$ with radius $R = 1$ lying to the right of the line $x = 2$, traversing from point $A(2; 5)$ to point $B(2; 3)$.

### b) Detailed Section Exercises

**Exercise 7.13:** Find the center and radius of the circle $(x + 3)^2 + (y - 3)^2 = 36$.

Solution for Exercise 7.13:
• The equation has the standard form $(x - a)^2 + (y - b)^2 = R^2$ with $a = -3$, $b = 3$, and $R^2 = 36$.
• Therefore, the circle has center $I(-3; 3)$ and radius $R = \sqrt{36} = 6$.

**Exercise 7.14:** Determine which of the following equations represent a circle, and find the center and radius of each valid circle:
a) $x^2 + y^2 + xy + 4x - 2 = 0$;
b) $x^2 + y^2 - 2x - 4y + 5 = 0$;
c) $x^2 + y^2 + 6x - 8y + 1 = 0$.

Solution for Exercise 7.14:
• a) The equation contains a cross-product term $xy$, so it cannot represent a circle.
• b) We have $a = 1, b = 2, c = 5$. Evaluating $a^2 + b^2 - c = 1^2 + 2^2 - 5 = 0$. The condition $a^2 + b^2 - c > 0$ is not satisfied (the solution set is just the single point $(1; 2)$). Hence, it is not a circle.
• c) We have $a = -3, b = 4, c = 1$. Evaluating $a^2 + b^2 - c = (-3)^2 + 4^2 - 1 = 9 + 16 - 1 = 24 > 0$. Hence, this is a circle with center $I(-3; 4)$ and radius $R = \sqrt{24} = 2\sqrt{6}$.

**Exercise 7.15:** Write the equation of the circle in each of the following cases:
a) Center $I(-2; 5)$ and radius $R = 7$;
b) Center $I(1; -2)$ and passing through point $A(-2; 2)$;
c) Diameter $AB$, with $A(-1; -3)$ and $B(-3; 5)$;
d) Center $I(1; 3)$ and tangent to the line $\Delta: x + 2y + 3 = 0$.

Solution for Exercise 7.15:
• a) Circle centered at $I(-2; 5)$ with radius $R = 7$:
$$(x + 2)^2 + (y - 5)^2 = 7^2 \Leftrightarrow (x + 2)^2 + (y - 5)^2 = 49.$$
• b) The radius is the distance $IA$:
$$R = IA = \sqrt{(-2 - 1)^2 + (2 - (-2))^2} = \sqrt{(-3)^2 + 4^2} = \sqrt{25} = 5$$
  Equation of the circle: $(x - 1)^2 + (y + 2)^2 = 25$.
• c) The center $I$ is the midpoint of diameter $AB$:
  $x_I = \frac{-1 + (-3)}{2} = -2$; $y_I = \frac{-3 + 5}{2} = 1 \Rightarrow I(-2; 1)$.
  Radius $R = \frac{AB}{2} = \frac{\sqrt{(-3 - (-1))^2 + (5 - (-3))^2}}{2} = \frac{\sqrt{(-2)^2 + 8^2}}{2} = \frac{\sqrt{68}}{2} = \sqrt{17}$.
  Equation of the circle: $(x + 2)^2 + (y - 1)^2 = 17$.
• d) Since the circle is tangent to line $\Delta$, the radius equals the distance from center $I$ to $\Delta$:
$$R = d(I, \Delta) = \frac{|1 + 2(3) + 3|}{\sqrt{1^2 + 2^2}} = \frac{|10|}{\sqrt{5}} = 2\sqrt{5}$$
  Equation of the circle: $(x - 1)^2 + (y - 3)^2 = (2\sqrt{5})^2 = 20$.

**Exercise 7.16:** In the coordinate plane, given triangle $ABC$ with vertices $A(6; -2)$, $B(4; 2)$, and $C(5; -5)$. Write the equation of the circumcircle of the triangle.

Solution for Exercise 7.16:
• Assume the general form of the circumcircle is:
$$x^2 + y^2 - 2ax - 2by + c = 0$$
• Since points $A, B, C$ lie on the circle, their coordinates satisfy the linear system:
$$\begin{cases} 6^2 + (-2)^2 - 12a + 4b + c = 0 \\\ 4^2 + 2^2 - 8a - 4b + c = 0 \\\ 5^2 + (-5)^2 - 10a + 10b + c = 0 \end{cases} \Leftrightarrow \begin{cases} -12a + 4b + c = -40 \\\ -8a - 4b + c = -20 \\\ -10a + 10b + c = -50 \end{cases}$$
• Solving this linear system of three equations yields: $a = 1$, $b = -2$, and $c = -20$.
• Check: $a^2 + b^2 - c = 1^2 + (-2)^2 - (-20) = 25 > 0$ (center $I(1; -2)$, radius $R = 5$).
• The equation of the circumcircle of $\triangle ABC$ is:
$$x^2 + y^2 - 2x + 4y - 20 = 0 \Leftrightarrow (x - 1)^2 + (y + 2)^2 = 25.$$

**Exercise 7.17:** Given the circle $(C): x^2 + y^2 + 2x - 4y + 4 = 0$. Write the equation of the tangent line $d$ to $(C)$ at point $M(0; 2)$.

Solution for Exercise 7.17:
• Substituting $M(0; 2)$: $0^2 + 2^2 + 2(0) - 4(2) + 4 = 4 - 8 + 4 = 0$ (verified), so $M \in (C)$.
• The circle has coefficients $a = -1, b = 2$, so its center is $I(-1; 2)$.
• A normal vector to the tangent line at $M$ is $\vec{IM} = (0 - (-1); 2 - 2) = (1; 0)$.
• The equation of the tangent line $d$ to $(C)$ at $M(0; 2)$ is:
$$1(x - 0) + 0(y - 2) = 0 \Leftrightarrow x = 0$$
(The tangent line is the $y$-axis itself).
